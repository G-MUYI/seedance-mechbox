# 变形不完全问题修复报告

## 问题诊断

经过全面分析，发现生成的提示词导致视频"变形不完全"的根本原因有以下几点：

### 1. 时间分配不合理 ⚠️ **已修复**

**问题**：基础模板 `seedance-mechbox` 的时间轴分配存在严重问题

| 阶段 | 旧版时间 | 新版时间 | 改进 |
|------|---------|---------|------|
| 主展开 | 1.8-8.8秒 (7秒) | 1.8-9.4秒 (7.6秒) | 延长0.6秒 |
| 锁扣闭合 | 8.8-10.0秒 (1.2秒) | 9.4-10.8秒 (1.4秒) | 延长0.2秒 |
| 终态停留 | 无独立阶段 | 10.8-12.0秒 (1.2秒) | **新增** ✅ |

**影响**：旧版在 8.8 秒才开始锁扣闭合，只留 1.2 秒完成，导致视频结束时还有部件未到位。

### 2. 缺少完成节点检查 ⚠️ **已修复**

**问题**：基础模板没有明确的完成节点要求

**新增检查点**：
- ✅ **8.0 秒前**：外轮廓成型 + 承重点到位
- ✅ **9.4 秒前**：全部目标识别部件可见且接近最终位置
- ✅ **10.8 秒前**：所有锁扣闭合，没有半展开面板
- ✅ **12.0 秒**：完整静止，无缺失部件

### 3. 复杂度控制缺失 ⚠️ **已修复**

**问题**：没有限制部件数量，可能生成过多部件导致时间不够

**新增规则**：
- 主要动作组上限：**6 组**
- 超过 6 组时：**先删减装饰性结构**，不延长时间
- 部件数量建议：车辆 8-12 个，动物 10-14 个，人偶 8-12 个

### 4. 缺少终态验收句 ⚠️ **已修复**

**问题**：时间轴写到最后没有明确说明"什么必须完成"

**新增验收清单**（10.8-12.0秒段落必须包含）：
```
完整 {目标物} 清楚可见，没有半展开面板、没有卡在 60% 的套筒、没有缺失轮组。
所有源开口都有对应部件或锁扣闭合解释。
承重点与桌面真实接触，有稳定压实阴影。
```

## 修复内容

### 1. 创建统一完成规则文档

**文件**：[shared/completion-rules.md](shared/completion-rules.md)

包含：
- 统一时间分配规则（12秒视频）
- 复杂度控制规则（6组上限）
- 终态验收清单模板
- 常见失败模式与修复方案
- 实施检查清单

### 2. 更新 seedance-mechbox 基础模板

**文件**：[skills/seedance-mechbox/references/generator.md](skills/seedance-mechbox/references/generator.md)

**主要改动**：

#### 时间轴调整
```diff
- [1.8-8.8 秒] 机械展开
- [8.8-10.0 秒] 锁扣闭合和完成

+ [1.8-9.4 秒] 机械展开（新增完成节点检查）
+ [9.4-10.8 秒] 锁扣、支架、传感器收尾
+ [10.8-12.0 秒] 终态稳定停留 + 验收清单
```

#### 新增完成节点要求
```
【完成节点前置】
8.0 秒前必须形成目标物的完整外轮廓和承重点
9.4 秒前必须看见全部目标识别部件且接近最终位置
9.4 秒后只允许做锁扣、支架、传感器、灯光和小型校准件的收尾
```

#### 新增终态验收句
```
完整 {车型} 清楚可见，没有半展开面板、没有卡在 60% 的套筒、没有缺失轮组。
所有源开口都有对应部件或锁扣闭合解释。
```

#### 新增复杂度控制规则
```
## 完整变形稳定规则

1. 主体复杂度上限：最多拆成 6 个主要动作组
2. 完成节点前置：8.0秒前外轮廓，9.4秒前识别部件
3. 终态验收句必须明确
4. 目标过复杂时先简化
```

### 3. 验证其他 generator

**已确认**：
- ✅ `seedance-world-cup-mechbox` 已有完整变形稳定规则
- ✅ `seedance-country-mechbox` 继承了相同的规则结构

## 预期效果

修复后，生成的提示词应该能够：

1. **时间充足**：有足够时间完成所有部件展开和锁扣闭合
2. **节奏清晰**：8.0秒、9.4秒、10.8秒三个检查点确保进度
3. **复杂度可控**：6组上限避免部件过多导致时间不够
4. **终态明确**：验收清单强制要求"完整、无缺失、无半展开"

## 使用建议

### 对于用户

如果你之前生成的提示词出现"变形不完全"问题，请：

1. **重新生成提示词**：使用更新后的 skill 重新生成
2. **检查时间轴**：确认是否有 9.4-10.8秒 和 10.8-12.0秒 两个独立阶段
3. **检查验收句**：确认最后是否写了"没有半展开、没有缺失"
4. **简化目标物**：如果目标物过于复杂，考虑简化（如"半身人偶"代替"全身+武器+底座"）

### 对于开发者

如果要创建新的 mechbox skill，请：

1. **参考 completion-rules.md**：遵循统一的时间分配和完成节点规则
2. **使用标准时间轴**：1.8-9.4s 展开 + 9.4-10.8s 收尾 + 10.8-12.0s 停留
3. **限制复杂度**：主要动作组 ≤ 6 组
4. **写明验收清单**：最后必须明确"没有半展开、没有缺失"

## 测试建议

建议测试以下场景验证修复效果：

1. **简单目标**（车辆）：应该在 9.4 秒前完成主要部件，10.8 秒前完全锁定
2. **复杂目标**（机械动物）：应该自动简化或在 6 组内完成
3. **卡通人偶**：应该在 9.4 秒前完成头身四肢，后背干净贴身
4. **对比测试**：用旧版和新版生成同一目标，对比完成度
