# 剩余 7 个 Skills 批量优化方案

基于前 3 个 skills 的优化经验，为剩余 7 个 skills 创建统一的优化策略。

## 优化原则（统一应用）

1. **长度目标**：200-450 字符（约 100-200 词）
2. **参考素材**：必选 @Image1/@Image2
3. **时间轴格式**：`[0s] [2s] [4s] [6s] [8s] [10s]` 6 个时间戳
4. **单 beat 简化**：每个时间点 1 个主动作
5. **删除元规则**：映射表、详细规则、否定约束外置到 generator.md
6. **正向守则**：删除大部分否定约束

## 各 Skill 特点分析

### 1. seedance-american-truckbox（366 行）
- **主题**：1980s-1990s 美国重卡
- **核心元素**：卡车型号、年代、驱动方式、地点、涂装
- **优化重点**：删除详细卡车规格，保留核心识别点

### 2. seedance-tiktok-us-mechbox（396 行）
- **主题**：美国 50 州 TikTok 内容
- **核心元素**：州名、州旗、州特色、TikTok 钩子
- **优化重点**：删除 TikTok 内容策略，专注视频提示词

### 3-7. seedance-zodiac-beast 系列（133-347 行）
- **主题**：十二生肖机械兽（5 个变体）
- **核心元素**：生肖、兽型、材质外壳、姿态
- **变体**：
  - zodiac-beast（主变形）
  - zodiac-beast-bust（胸像）
  - zodiac-beast-crest（纹章盾）
  - zodiac-beast-diorama（微缩场景）
  - zodiac-beast-mask（面具）
- **优化重点**：5 个变体共享核心结构，只改变目标物类型
