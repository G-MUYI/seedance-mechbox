# 有图 vs 无图参考的提示词对比

## 核心原则

根据 `seedance-prompt-research.md`：
- **参考素材角色分配**是最高权重要素（22%）
- **有参考图时**：依赖 @Image1/@Image2 提供外观信息
- **无参考图时**：在主体描述中补充关键外观特征（15-25 字）

## 总结

### 何时使用有参考图版本

✅ **推荐场景**：
- 用户提供了参考图
- 目标物外观复杂（如特定车型、特定动物）
- 需要精确控制外观细节
- 追求最高生成质量

**优势**：
- 参考素材占 22% 权重（最高）
- 提示词更简洁（约 380-420 字符）
- 外观控制更精确

### 何时使用无参考图版本

✅ **适用场景**：
- 用户未提供参考图
- 目标物外观可以用简短文字描述清楚
- 快速生成，不追求极致精确

**优势**：
- 不依赖外部图片
- 仍然保持在 50-200 词甜点区（约 410-450 字符）
- 通过"最终目标"行补充关键特征

### 关键原则

1. **优先推荐有参考图**：符合研究报告的最高权重要素
2. **无图时补充外观**：在主体描述中添加"最终目标"行（15-25 字）
3. **保持长度控制**：无论有图无图，都控制在 200-450 字符
4. **时间轴呼应**：无图版本在时间轴中使用更具体的外观描述

## 实施建议

### 生成逻辑

```python
if user_provided_image:
    # 使用有参考图版本
    prompt = f"@Image1 作为 {target} 外观参考..."
else:
    # 使用无参考图版本
    prompt = f"最终目标：{target_key_features}..."
```

### 外观特征提取规则

**车辆类**：
- 轮廓（楔形/方正/流线）
- 前脸特征（格栅/灯组/前唇）
- 关键部件（轮拱/车鼻/尾翼）

**动物类**：
- 体型（低趴/高大/紧凑）
- 头部特征（角/耳/喙）
- 关键部件（四肢/翅膀/尾部）

**器物类**：
- 主要形态（盾形/球形/柱形）
- 识别特征（浮雕/透镜/框架）
- 功能部件（支架/底座/边框）

**字数控制**：15-25 字，不超过 30 字
