## 修复策略

### 方案 A：逐个手动修复（推荐用于关键 skills）
- **优点**：精确控制，质量高
- **缺点**：耗时长（约 15-20 小时）
- **适用**：seedance-mechbox, american-truckbox, country-mechbox

### 方案 B：批量模式修复（推荐用于相似 skills）
- **优点**：快速，一致性好
- **缺点**：可能需要微调
- **适用**：zodiac-beast 系列（5 个 skills 共性问题）

### 方案 C：Agent 辅助修复（推荐用于大规模修复）
- **优点**：快速，可并行
- **缺点**：需要验证
- **适用**：所有待修复 skills

## 修复模板

基于 seedance-mechbox 的修复经验，总结出标准修复模板：

### 步骤 1：删除冗余段落
```diff
- ❌ 删除"注意事项"段落（12+ 条硬规则）
- ❌ 删除"污染词清单"表格
- ❌ 删除"与其他 skill 的关系"段落
- ❌ 删除"用户追问常见场景"详细列表
- ❌ 删除映射表详细规格（只保留映射表本身）

+ ✅ 添加"关键规则提醒"段落（5 条核心规则）
+ ✅ 添加"常见问题修复"段落（4 条关键修复点 + 引用 FIXES.md）
```

### 步骤 2：压缩输出模板
```diff
主体段落：
- ❌ 删除重复解释性描述
- ❌ 删除"不是XX、不是YY"等否定式描述
- ❌ 删除过于详细的材质描述

+ ✅ 保留核心结构描述
+ ✅ 保留关键数值（1-3mm 装配缝）
+ ✅ 保留质量守恒和反剧透要求

时间轴段落：
- ❌ 删除每个 beat 的重复解释
- ❌ 合并相邻动作组

+ ✅ 每个 beat 只描述一个主要动作
+ ✅ 明确完成节点（8.0秒、9.4秒、10.8秒）
```

### 步骤 3：优化时间轴密度
```diff
- ❌ 旧版（7-9 个 beat）
[0.0-1.4] 触发
[1.4-1.8] 坠落
[1.8-2.7] 顶盖裂开
[2.7-3.6] 底盘轮组
[3.6-4.8] 中段骨架
[4.8-5.9] 侧板翼子板
[5.9-7.2] 前端车鼻
[7.2-9.4] 前灯组件
[9.4-10.8] 锁扣收尾

+ ✅ 新版（5 个 beat）
[0.0-1.8] 触发与坠落
[1.8-4.0] 底盘轮组（顶盖裂开 + 底部顶出）
[4.0-6.6] 车身骨架（中段 + 侧板）
[6.6-9.4] 前脸灯组（前端 + 灯组）
[9.4-12.0] 锁扣收尾与终态停留
```
