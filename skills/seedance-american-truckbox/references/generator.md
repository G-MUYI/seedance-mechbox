# Seedance 80/90 年代美式重卡机械魔盒提示词生成器（对应 /seedance-american-truckbox 命令）

为字节跳动 Seedance 2.0 视频模型生成「按下按钮 → 魔盒坠落 → 串行机械展开为 1980s-1990s 美国地区 Class 8 美式重卡拖头」的中文提示词。本 skill 与 `seedance-mechbox`（豪车系列）并行，把目标物从超跑 / 豪华车替换为美式公路重卡，强调长车鼻、镀铬格栅、外露排气管、卧铺舱、油箱、轮组、示宽灯、铆钉和重载底盘。

默认只生成「tractor head / semi tractor / 拖头」，不生成完整挂车。挂车会显著增加质量守恒难度，除非用户明确要求「带挂车 / 18 轮整车 / 半挂车完整展开」。

提示词结构沿用 Seedance 2.0 偏好的「镜头 → 主体 → 时间轴 → 机械规则 → 关键限制」编排。默认输出完整版提示词，主干用正向描述，仅在「关键限制」保留少量必要负向项。真实品牌与车型只作为时代比例和造型语言参考，输出时用替代铭牌，不生成真实商标、车标或品牌 Logo。

## 触发条件

**应触发**：

- 用户输入 `/seedance-american-truckbox` 或 `/seedance-american-truckbox <编号 / 款名 / 车型关键词>`
- 用户输入 `/seedance-truckbox`、`/truckbox`、`/american-truckbox`
- 用户描述「机械盒掉下来变成 80/90 年代美式重卡 / 大卡车 / 半挂拖头 / cabover / long nose truck」类视频脚本需求
- 用户要求把现有 `seedance-mechbox` 豪车系列改成「美国 80、90 年代大卡车系列」

**不应触发**：

- 用户明确要求现代电动卡车、皮卡、军车、消防车、工程机械等非美式公路重卡主题
- 用户要求其他视频模型（Sora / Kling / Veo / Runway 等）的提示词
- 静态图像提示词需求
- 用户要求真实品牌广告片、真实 Logo 复刻或车标精确再现

## 参数

`/seedance-american-truckbox [编号|款名|车型关键词] [--trailer]`

- **不传参** → 从 12 款中随机抽一个，并在输出前一行告知「本次抽中：No.X × 款名」
- **传入编号**（1-12 / No.1 / 01）→ 走对应款式
- **传入款名或关键词**（long nose / cabover / 379 / W900 / FLD / Mack / Marmon 等）→ 自动匹配最近的款式
- **`--compact` / 短版 / 紧凑版 / 压缩版** → 默认仍输出完整版；如用户或平台给出硬字符上限，只做结构保留型精简，不能删镜头规则、阶段时间轴、质量守恒、材质细节、拖头范围和关键限制
- **`--trailer` 标志 / 明确要求带挂车** → 只追加短段挂车前墙和一小段车架，并且从反推初始魔盒阶段就规划源开口；挂车结构必须在识别成型阶段前完成主体来源，收尾阶段只做鞍座、空气管接口、锁扣和支架闭合，不在结尾新增挂车大件；完整长挂车建议拆成独立目标或使用平台长时长参数

## 各款详细规格

每款都包含：① 魔盒主轮廓 / ② 前端锚点 / ③ 源开口 / ④ 串行展开顺序 / ⑤ 节奏微调 / ⑥ 灯光材质 / ⑦ 易失败点。

### 01 · Chrome Long-Nose · HIGHWAY/87

- **主轮廓**：加长硬边矩形匣，前端略窄，顶部纵向中心分缝明显，像压缩后的长车鼻机械舱。
- **前端锚点**：FRONT/01 + 竖向镀铬格栅骨架凹窗 + 四颗大圆头螺栓。
- **源开口**：前端三段套筒口用于长车鼻和格栅；底部六组轮舱滑轨；两侧狭长铰链槽用于油箱、踏板和排气管。
- **展开顺序**：① 底部车架梁与前后轴顶出 → ② 六轮组分批下放 → ③ 后部卧铺舱从中段翻开升起 → ④ 两侧油箱、踏板、空气滤清器沿滑轨抽出 → ⑤ 前端长车鼻三段伸出，竖格栅扣合 → ⑥ 双排气管竖起，示宽灯依次点亮。
- **节奏**：长鼻伸出时阻尼最强，推进到 60% 后回退 5%，再以金属扣合完成。
- **灯光材质**：黑色哑光装甲 + 镀铬格栅 / 油箱 / 排气管，琥珀色顶灯和侧灯。
- **易失败点**：不要让车头在初始触发和落桌碰撞阶段提前像完整 Peterbilt；品牌只作比例参考，主铭牌写 HIGHWAY/87。

## 注意事项

**硬规则**：

1. **真实品牌 anti-bias**：真实车型名只用于比例参考。主铭牌必须是 HIGHWAY/87、WIDEHOOD/82、AERO/87 等替代编号。不要要求生成真实品牌 Logo。
2. **默认只做拖头**：完整挂车会破坏质量守恒。用户明确要求挂车时，只生成短段挂车前墙和一段车架，并提前规划源开口；完整挂车建议作为独立目标或使用平台长时长参数。
3. **FRONT/01 从初始画面锚定**：最终车头必须由 FRONT/01 面展开。不能到最后才指定朝向。
4. **COE 与 conventional 分清**：COE 款（10、11）不要长车鼻；长鼻款（01、02、04）不要变成平头。
5. **80/90 年代感优先**：避免现代电动卡车、超流线新能源车、欧洲高顶拖头、皮卡或怪兽卡车先验。
6. **重卡专属部件必须来自源开口**：格栅、保险杠、油箱、踏板、排气管、镜架、轮组、卧铺舱、牵引鞍座都要有可见来源。
7. **灯光用琥珀示宽灯建立年代感**：顶灯、侧灯、边灯可以依次点亮，但不能变成赛博霓虹。
8. **真实感必须落在物理证据上**：必须写轮胎接地、接触阴影、车架承重、体积守恒、制造痕迹、装配缝、透镜厚度和一致光源；不要只堆镀铬、重型、精密等形容词。
9. **动作词保持重机械**：使用「高延迟、重阻尼、强摩擦、阶段性停滞、错齿、迟滞、逐级到位、扣合」，避免「流畅、顺滑、灵活、轻快」。
