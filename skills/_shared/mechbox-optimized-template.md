# Seedance 机械魔盒通用优化提示词模板

本文档为所有机械魔盒系列 skills 提供统一的优化提示词模板。

## 适用范围

- seedance-american-truckbox
- seedance-tiktok-us-mechbox
- seedance-zodiac-beast（及其 4 个变体）

## 核心优化原则

基于 `shared/references/seedance-prompt-research.md`：

1. **长度**：200-400 字符（约 50-200 词，机械魔盒系列约 380-420 字符）
2. **权重分配**：参考素材(22%) + 任务描述(18%) + 镜头/时间(17%)
3. **时间轴**：`[0s] [2s] [4s] [6s] [8s] [10s]` 显式时间戳
4. **单 beat**：每个时间点 1 个主动作 + 1 个主镜头
5. **正向守则**：删除大部分否定约束

```

```

正前端镂空机芯窗，可见齿轮与连杆，中心轴承。
装甲面板{主色}哑光{材质}，骨架{副色}抛光金属。

**关键差异**：
- **有图**：参考素材占 22% 权重，主体描述更简洁（约 350 字符）
- **无图**：用"最终目标"行补充外观信息，总长度增加到约 380-400 字符

[0s] 双手托住魔盒，{触发动作}，{主题元素}增强发光，松手下坠。
[2s] 魔盒砸到桌面，轻微弹跳后稳定，顶盖齿轮转动，外壳沿分缝裂开。
[4s] 底部滑轨顶出{承重结构}，接触桌面，压实阴影清楚。
[6s] 中段装甲板翻开形成{核心骨架}，两侧{关键部件}翻折到位。
[8s] 前端伸缩机构抽出形成{前端识别部件}，{灯光细节}点亮。
[10s] 锁扣闭合，完整 {目标物} 定型，{主题特征}清楚可见。

机械动作：高延迟、重阻尼、串行展开。
所有零件从魔盒外壳、滑轨、套筒中推出，传力路径清楚。
{主色}与{副色}贯穿盒体与目标物，{主题特征}融入装甲分区。
保持真实接触阴影、金属高光、轻微呼吸式手持观察。
```

**目标长度**：约 380-420 字符

## 各 Skill 填充指南

### american-truckbox

**标题格式**：
```
美国重卡机械魔盒｜{年代} {卡车型号}｜{主铭牌}
```

**主题特征机械化**：
```
铆钉装甲、镀铬边框、{驱动方式}标识、{公路涂装}条纹。
```

**示例变量**：
- 年代：1980s / 1990s
- 卡车型号：Peterbilt 379 / Kenworth W900 / Freightliner Classic
- 主铭牌：USA/HIGHWAY-01
- 主色：深蓝 / 黑色
- 副色：镀铬 / 琥珀
- 承重结构：重载轮组与悬挂
- 前端识别部件：方形车鼻与格栅

### tiktok-us-mechbox

**标题格式**：
```
美国州主题机械魔盒｜{州名} {State}｜{目标物}｜{主铭牌}
```

**主题特征机械化**：
```
{州旗色调}装甲分区、{州特色元素}浮雕（如德州星、加州熊轮廓）。
```

**示例变量**：
- 州名：德克萨斯 Texas / 加利福尼亚 California
- 目标物：油田巡检车 / 海岸救援车
- 主铭牌：TEXAS/OIL-01 / CALIFORNIA/COAST-01
- 主色：深蓝 / 金色
- 副色：白色 / 红色
- 州特色元素：孤星浮雕 / 熊爪刻线

### zodiac-beast（主变形）

**标题格式**：
```
十二生肖机械兽｜{生肖中文} {Zodiac}｜{兽型}｜{主铭牌}
```

**主题特征机械化**：
```
{生肖符号}蚀刻、{兽型特征}装甲轮廓、{材质外壳}分段护甲。
```

**示例变量**：
- 生肖：龙 Dragon / 虎 Tiger / 兔 Rabbit
- 兽型：机械龙 / 机械虎 / 机械兔
- 主铭牌：DRAGON/01 / TIGER/01 / RABBIT/01
- 主色：金色 / 黑色 / 白色
- 副色：红色 / 橙色 / 粉色
- 承重结构：四足液压支架 / 尾部平衡架
- 前端识别部件：龙头 / 虎头 / 兔头，眼部透镜

## 使用说明

1. **各 skill 的 SKILL.md** 应该指向本文档或创建自己的 generator-optimized.md
2. **映射表和详细规则** 保留在各自的 generator.md 中
3. **用户可选**：明确要求"详细版"时使用原 generator.md

## 关键删减内容

所有 skills 统一删除：
- ❌ 详细映射表（外置到 generator.md）
- ❌ 过度详细的主体描述（压缩到 6-8 句话）
- ❌ 冗长的时间轴描述（改为 6 个时间戳）
- ❌ 全局动作语义详述（压缩为 1 句话）
- ❌ 大部分否定约束（改为正向守则）
- ❌ 元规则和生成逻辑（属于 generator.md）

## 保留的核心内容

所有 skills 统一保留：
- ✅ 参考素材角色分配（@Image1/@Image2）
- ✅ 任务描述（掌心大小硬边机械魔盒）
- ✅ 镜头设定（1 句话）
- ✅ 时间轴（6 个时间戳）
- ✅ 主题特征（融入装甲、材质、铭牌）
- ✅ 核心识别点（启动键、机芯窗、轴承）
- ✅ 机械动作（1 句话）
- ✅ 物理规则（2 句话）

## 验证清单

优化版是否符合研究报告要求：

- ✅ 长度在 50-200 词（约 200-400 字符，机械魔盒系列约 380-420 字符）
- ✅ 参考素材角色分配明确（22% 权重）
- ✅ 时间轴使用显式时间戳（17% 权重）
- ✅ 每个时间点只描述 1 个主动作 + 1 个主镜头
- ✅ 删除大部分否定约束（负向提示仅 2% 权重）
- ✅ 使用具体摄影术语（不用模糊形容词）
- ✅ 材质对比清晰（主色/副色明确）
- ✅ 保留核心识别点（触发机构、机芯窗、轴承）
- ✅ 机械动作用具体词汇（高延迟、重阻尼、串行展开）
- ✅ 正向守则优先（"保持"而非"避免"）
