## 共享规则：主体外壳随机化

- 每次生成时，先锁定星座，再从该星座的「主体外壳特征」中随机取 2-3 个可见特征写入初始盒体；不得跨星座借用外壳特征。
- 再随机追加 1 个工艺变化：斜切滑盖、环形旋闸、偏心齿环、透明观察窗、压铸编号、外露液压槽、嵌套套筒、微型散热鳍片、错层装甲瓣、细窄状态灯带。
- 外壳描述必须让初始触发和落桌碰撞阶段的盒体第一眼就有星座专属气质，但仍保持纯可变形盒体，不提前露出完整的变体目标物或完整标志部件。
- 避免所有主体都照抄「分瓣装甲、硬边棱面、八角锁环、镂空传动窗」这一套固定外壳词；这些只能作为基础结构，不能替代星座专属外壳。

## 共享参数规则

所有变体 generator 均支持以下参数：

- **不传参** → 从十二星座随机抽取，输出前标注抽中结果
- **传入星座名**（白羊座 / Aries / ♈ 等）→ 走对应规格
- **默认** → 输出完整版提示词
- **`--compact` / 短版 / 紧凑版 / 压缩版** → 默认仍输出完整版；如用户或平台给出硬字符上限，只做结构保留型精简，保留镜头规则、时间轴主拍、主要部件五拍节奏、质量守恒和关键限制
- **`--expanded`** → 兼容旧用法，等同于默认完整版

## 共享扩写规则（通用部分）

默认输出时，不要只输出骨架；按以下规则扩写到完整版：

- **镜头**：补足连续手持观察感、45-60 厘米距离、主体占比、桌面留白、撞击反应震动、展开时小幅观察式微运镜、结尾呼吸式停留和锁定后轻微小动作。
- **主体**：扩写高密度、重型、精密结构；必须写入当前星座的{主体外壳特征}，并随机选择 1 个工艺变化，避免每次都使用同一套固定外壳；参考图模式下让初始盒材质继承目标参考图材质。各变体 generator 补充需要写清的具体部件清单。
- **时间轴**：每个阶段写清一个主动作组和必要物理结果；主要部件组保留抖动定位、受阻推进、回退 5%、再次推进、锁扣闭合，小件不重复完整五拍；前一组到位才触发下一组。
- **物理与音频**：拆开写零件来源、刚性连接、材质、反馈和声音；强调源开口保留为镂空痕迹，传力路径可见。
- **真实感**：补足体积守恒、承重点、接触阴影、制造痕迹、1-3mm 装配间隙、指纹灰尘、焦点呼吸和一致光源；LED 保持克制，不能变成魔法光效。
- **完整版长度**：默认输出完整版本；硬字符上限时只做结构保留型精简，必须保留镜头规则、主要部件五拍微循环、质量守恒、FRONT/01、材质细节、物理来源和关键限制。

各变体 generator 补充自己的识别部件扩写要求和长度说明。
