# 倒推式机械魔盒生成模板

## 核心理念

**不是套模板填空，而是从目标物的结构特征倒推机械盒子的设计。**

## 生成流程

### 第一步：分析目标物

当用户给出目标物（如"龙"、"卡车"、"螃蟹"）时，先进行结构分析：

```
目标物：{用户输入}

结构分析：
1. 整体形态类型
   - 长条形（龙、蛇、火车）
   - 球形/块状（螃蟹、乌龟、坦克）
   - 高耸形（长颈鹿、起重机、灯塔）
   - 展开形（鸟、飞机、风筝）
   - 多足形（蜘蛛、章鱼、多轴车）

2. 关键部件识别
   - 头部/前端：{特征}
   - 躯干/主体：{特征}
   - 四肢/支撑：{特征}
   - 尾部/后端：{特征}
   - 附属结构：{翅膀/触角/装备}

3. 运动/展开逻辑
   - 蜿蜒式（脊椎节段依次解锁）
   - 包覆式（甲壳从中心向外翻开）
   - 折叠式（翼/臂从收纳状态展开）
   - 伸缩式（套筒结构依次推出）
   - 组装式（零件从不同方向汇聚）
```

### 第二步：倒推机械盒子

根据目标物特征，设计初始盒子：

```
机械盒子设计：

1. 盒子形状
   - 长条形目标物 → 长方体盒子，主轴明显
   - 球形目标物 → 多面体球壳，赤道分缝
   - 高耸形目标物 → 垂直圆柱，底座加厚
   - 展开形目标物 → 扁平盒子，侧面有折叠槽
   - 多足形目标物 → 中心块+周边舱门

2. 分缝布局
   - 每个关键部件对应一个源开口
   - 分缝位置预示展开方向

3. 触发机构
   - 与目标物主题相关的启动方式
   - 例如：龙→龙鳞纹按钮，卡车→方向盘旋钮

4. 前端识别
   - 机芯窗内的图案预示最终形态
   - 例如：龙→齿轮排列成龙纹，螃蟹→八角锁环
```

### 第三步：设计变形序列

**关键原则：变形顺序必须符合目标物的结构逻辑**

```
时间轴设计（6个关键帧）：

[0s] 触发与坠落
    - 触发动作与目标物主题呼应
    - 例如：龙→按下龙鳞按钮，卡车→旋转方向盘

[2s] 第一阶段：建立支撑/基础
    - 长条形：脊椎开始解锁
    - 球形：底部支撑先展开
    - 高耸形：底座先稳定
    - 展开形：中心轴先固定
    - 多足形：支脚先落地

[4s] 第二阶段：主体成型
    - 长条形：身体节段依次展开
    - 球形：甲壳翻开露出内部
    - 高耸形：主体向上升起
    - 展开形：翼/臂开始展开
    - 多足形：腿部依次伸出

[6s] 第三阶段：关键部件
    - 头部/前端伸出
    - 特征部件到位（角/爪/翼）

[8s] 第四阶段：细节完善
    - 次级部件展开
    - 灯光系统激活

[10s] 第五阶段：锁定成型
    - 所有锁扣闭合
    - 最终姿态定型
    - 特征动作（龙甩尾/螃蟹张钳/卡车鸣笛）
```

## 示例对比

### 旧方式（套模板）

```
目标物：龙
→ 填入通用模板
→ 时间轴固定为：[0s]触发 [2s]砸桌 [4s]底座 [6s]装甲 [8s]前端 [10s]锁定
```

### 新方式（倒推）

```
目标物：龙

分析：
- 形态：长条形，有脊椎节段
- 关键部件：龙头、四爪、翅膀、长尾
- 运动逻辑：蜿蜒展开

倒推盒子：
- 形状：长条形多面体，脊椎分缝明显
- 触发：龙鳞纹按钮
- 机芯窗：齿轮排列成龙纹

变形序列：
[0s] 按下龙鳞按钮，龙纹发光，松手下坠
[2s] 盒子砸桌，脊椎分缝开始解锁（从尾到头）
[4s] 四爪从腹部液压舱弹出，抓地稳定
[6s] 龙头从前端伸缩套筒中推出，颈部装甲合拢
[8s] 背部翅膀从折叠槽展开，翼骨锁定
[10s] 长尾甩动定型，龙眼透镜点亮，低吼姿态
```

## 不同形态类型的变形模式参考

### 长条形（龙、蛇、火车、卡车）

**盒子特征**：长方体，主轴明显，脊椎分缝
**变形逻辑**：
1. 脊椎节段依次解锁（波浪式传导）
2. 支撑结构展开（轮/足/履带）
3. 头部从前端伸出
4. 尾部/后端定型

### 球形/块状（螃蟹、乌龟、坦克）

**盒子特征**：多面体球壳，赤道分缝或顶盖分瓣
**变形逻辑**：
1. 顶盖/甲壳翻开（包覆式）
2. 支脚从侧面舱门伸出
3. 头部/炮塔从中心升起
4. 钳/臂从前端展开

### 高耸形（长颈鹿、起重机、灯塔）

**盒子特征**：垂直圆柱，底座加厚
**变形逻辑**：
1. 底座先沉降稳定
2. 主体分段向上升起（伸缩式）
3. 颈部/臂架逐节展开
4. 头部/顶端最后到位

### 展开形（鸟、飞机、风筝）

**盒子特征**：扁平盒子，侧面折叠槽明显
**变形逻辑**：
1. 中心轴/机身先固定
2. 翼从两侧折叠槽展开
3. 头部/机头前伸
4. 尾翼/尾羽最后展开

### 多足形（蜘蛛、章鱼、多轴车）

**盒子特征**：中心块+周边多个舱门
**变形逻辑**：
1. 支脚分批从周边伸出（对称式）
2. 中心主体稳定
3. 头部/驾驶舱升起
4. 触手/臂架依次到位

## 关键原则

1. **结构决定形态**：盒子形状必须预示最终目标物
2. **逻辑决定顺序**：变形序列必须符合物理和结构逻辑
3. **特征决定细节**：触发机构、机芯窗图案、铭牌都要呼应主题
4. **每个目标物都是独特的**：不要用同一套时间轴应对所有目标

## 生成检查清单

生成提示词前，确认：

- [ ] 分析了目标物的核心结构特征
- [ ] 盒子形状与目标物形态呼应
- [ ] 变形序列符合目标物的展开逻辑
- [ ] 每个时间点描述的是该目标物特有的动作
- [ ] 触发机构、机芯窗、铭牌都与主题相关
- [ ] 不是简单套用通用模板
