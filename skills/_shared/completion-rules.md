# 机械魔盒完整变形规则

## 适用范围

本规则用于所有 Seedance 机械魔盒类 skill 的完成度校验。它只定义动作阶段和验收标准，不绑定具体秒数；具体时长由平台参数、用户要求或单个 skill 的参考文件决定。

## 核心原则

1. **完成节点前置**：不要把主要部件展开拖到结尾阶段。
2. **复杂度上限**：控制主要动作组数量，而不是靠延长提示词或堆叠时间戳解决。
3. **阶段式时间轴**：最终提示词内部优先写“阶段一、阶段二、展开段”等动作进度；只有 skill 明确要求秒数且秒数不冲突时，才写具体时间码。
4. **终态验收**：结尾必须明确目标物已经完整锁定，并列出不能缺失的关键部件。

## 统一阶段分配

| 阶段 | 允许的动作 | 禁止的动作 |
|---|---|---|
| 初始触发阶段 | 手部触发、松手、主体开始下坠 | 提前露出完整目标物 |
| 落桌碰撞阶段 | 真实撞击、轻微弹跳、接触阴影压实 | 切镜头、悬浮或瞬移 |
| 主体展开前半程 | 外轮廓、承重点、底盘/四肢/支架、主体骨架成型 | 只做装饰细节而不建立结构 |
| 识别成型阶段 | 前端/头部/主识别面、轮组/四肢/关键功能件、主要比例到位 | 新增大型主体块 |
| 收尾锁定阶段 | 锁扣、支架、传感器、灯光、纹理、小型校准件 | 继续展开车鼻、头部、翅膀、座舱等主体大件 |
| 终态稳定阶段 | 同一构图下稳定停留、可读验收、接触阴影保持 | 新增部件、换角度展示、进入新镜头 |

## 关键检查点

- 主体展开前半程结束前：外轮廓和承重点必须成型。
- 识别成型阶段结束前：全部目标识别部件必须可见且接近最终位置。
- 收尾锁定阶段结束前：所有锁扣闭合，没有半展开面板或卡在中途的套筒。
- 终态稳定阶段：完整目标物清楚可见，无缺失关键部件，不补新主体结构。

## 复杂度控制

主要动作组默认不超过 6 组：

1. 顶盖裂开与外壳分缝。
2. 底部承重结构、轮组、四肢或底座顶出。
3. 中段装甲板翻开，形成主体骨架。
4. 两侧侧板、翼板、护甲或功能侧件展开。
5. 前端、头部、车鼻、主识别面或核心机构成型。
6. 识别细节、锁扣、支架、灯光和小件完成。

超过 6 组时，先删减装饰性结构，合并相似动作组，或把目标物简化为更容易完整展开的单体收藏模型；不要把新的主体大件推迟到结尾阶段。

## 终态验收句

结尾阶段必须写出类似句式：

```text
完整 {目标物} 清楚可见，没有半展开面板、没有卡在中途的套筒、没有缺失 {关键部件清单}。所有源开口都有对应部件或锁扣闭合解释，承重点与桌面真实接触，接触阴影稳定，灯光和反射不抢走结构可读性。
```

## 常见失败修复

- **结尾还在组装主体**：把车鼻、头部、翅膀、四肢、座舱、轮组等主体大件提前到主体展开和识别成型阶段。
- **部件太多导致展开不完**：压缩到 6 个以内主要动作组，删掉额外灯带、非功能护板、多余散热片和重复装饰。
- **缺少终态验收**：补完整可见、无半展开、无缺失关键部件、源开口闭合、承重点接触、阴影稳定。
- **人偶后背过厚**：把后侧板、顶盖和边角体积折入肩胛、腰胯和腿部结构；后背只保留贴身薄甲、窄脊柱轨和小型接口。

## 生成前检查

- [ ] 时间轴是否使用阶段表达，且没有与平台时长冲突的硬秒数？
- [ ] 外轮廓和承重点是否在前半程完成？
- [ ] 识别部件是否在收尾前全部可见？
- [ ] 主要动作组是否不超过 6 组？
- [ ] 终态验收是否明确“完整、锁定、无缺失、真实接触”？
