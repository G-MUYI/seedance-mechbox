# 提示词长度和权重分配（基于 Seedance 2.0 研究报告）

## 核心原则

默认输出遵循所选 skill 的详细完整版合同。只有用户或平台给出硬字符上限时，才参考 **50-200 词** 甜点区做结构保留型压缩（带参考素材的 I2V/R2V 可以更短）。

## 权重分配

| 要素 | 权重 | 优先级 |
|------|------|--------|
| 参考素材角色分配 | 22% | 最高 - 必须放在最前面 |
| 任务描述（主体/动作/场景） | 18% | 高 |
| 镜头/时间结构 | 17% | 高 - 每拍只放一个主动作和一个主镜头 |
| 风格/灯光 | 9% | 中 |
| 上下文/背景 | 8% | 中 |
| 约束（正向 guardrails 优先） | 7% | 中 - 最多 1-2 条必要负向项 |
| 参数 | 7% | 中 |

## 压缩时的优先级（按保留顺序）

1. 参考素材角色分配（22%）- @Image/@Video/@Audio 必须有清晰职责
2. 任务描述：主体、动作、场景（18%）- 简洁准确，不要冗余
3. 镜头/时间结构（17%）- 保留每个 beat 一个主动作，不要过载
4. 风格/灯光（9%）- 用具体摄影术语代替模糊形容词
5. 约束（7%）- 正向 guardrails 优先，避免密集负向列表
6. 其他 - 在不影响前 5 项的前提下可精简

## 必须避免的陷阱

- ❌ 单个 beat 里塞太多动作和镜头 → ✅ 每拍只放一个主动作
- ❌ 用 "epic、beautiful、cool" 这类模糊形容词 → ✅ 用具体摄影/灯光术语
- ❌ 在压缩场景中提示太长、修辞太多，后半段把前半段冲淡 → ✅ 按权重做结构保留型精简
- ❌ 密集负向约束列表 → ✅ 正向 guardrails 优先，再加 1-2 条必要负向项

## 时间轴格式

用简洁的时间戳 `[0s] ... [3s] ... [6s] ...`，每 beat 只写**一个主要变形动作** + **一个手持反应/观察提示**。

## 默认输出策略

- 默认输出所选 skill 的**详细完整版提示词**，不要默认输出精简版、摘要版或骨架版
- `--full` / `--完整版` 兼容旧用法，等同于默认详细完整版
- 只有用户明确要求短版、`--compact`，或平台存在硬字符上限时，才按上述权重分配做结构保留型精简；精简后仍必须保留参考图材质职责、初始盒反推、阶段时间轴、质量守恒、终态小动作和关键限制
