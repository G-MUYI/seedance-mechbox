# Seedance 黄道十二神兽装甲体纹章盾牌提示词生成器（对应 /seedance-zodiac-beast-crest 命令）

为 Seedance 2.0 生成「按下按钮 → 可变形盒体坠落 → 严格串行展开为黄道十二星座神兽装甲体纹章盾牌」的中文提示词。本 skill 复用 `seedance-zodiac-beast` 的神兽设定，但最终物体是竖立在桌面的结构盾牌、徽章、家族纹章或浮雕铭牌，不是完整神兽装甲体。

视觉核心是「盾面 + 结构浮雕 + 星座刻印环」：神兽头、角、钳、鬃、尾针、弓、瓶口、双鱼等元素以浮雕、结构层板、联动轮暗纹和可动徽章形式分层嵌入盾面上。

**共享规则**：主体外壳特征表、外壳随机化规则、参数规则、共享输出段落和扩写规则的通用部分均定义在 `../_shared/zodiac-beast-variant-base.md`，本文件不再重复。

## 触发条件

**应触发**：

- 用户输入 `/seedance-zodiac-beast-crest` 或 `/seedance-zodiac-beast-crest <星座名>`
- 用户描述「星座神兽装甲体纹章 / 盾牌 / 徽章 / 浮雕铭牌 / 家徽」
- 用户想保留神兽装甲体主题，但最终展示物体是平面偏立体的结构纹章

**不应触发**：

- 用户要胸像 / 头雕 → 走 `seedance-zodiac-beast-bust`
- 用户要面具 / 头盔 → 走 `seedance-zodiac-beast-mask`
- 用户要微缩场景 → 走 `seedance-zodiac-beast-diorama`
- 用户要完整全身神兽 → 走 `seedance-zodiac-beast`

## 变体专属扩写补充

在共享扩写规则基础上，纹章盾牌变体额外要求：

- **主体部件清单**：写清背部支架、底部支脚、盾缘外框、中央内构浮雕、结构徽章层、星座刻印环和 FRONT/01 传动窗。
- **纹章识别**：强化盾面浮雕里的神兽头、角、钳、鬃、尾针、弓、瓶口、双鱼环等标志，但避免生成完整站立神兽或平面贴纸徽章。
- **完整版长度**：把纹章盾牌细节写完整。

## 注意事项

- 必须写背部支架或底部支脚，避免盾牌漂浮。
- 真实感优先检查背部支架、底部支脚、接触阴影、浮雕层厚度和制造痕迹。
- 神兽只以结构浮雕、徽章层板和盾缘结构呈现，不生成完整站立神兽。
- 纹章不能像贴纸：强调金属蚀刻、浮雕层、铰链层板、可动徽章和镂空内构。
- 盾面正面从初始画面由 FRONT/01 锚定。
