# Seedance 黄道十二神兽机甲胸像提示词生成器（对应 /seedance-zodiac-beast-bust 命令）

为 Seedance 2.0 生成「按下按钮 → 机械魔盒坠落 → 严格串行展开为黄道十二星座神兽机甲胸像 / 头雕」的中文提示词。本 skill 复用 `seedance-zodiac-beast` 的十二星座神兽设定，但最终物体不再是完整全身神兽，而是带底座、肩甲、颈柱和头部特征的收藏级机械胸像。

重点是「桌面收藏雕像」：头部、角、鬃、钳、尾针、弓、瓶口、双鱼环等识别部件集中在上半身；下半身不完整展开，只以底座、胸甲、肩甲和机械颈柱承接。

## 触发条件

**应触发**：

- 用户输入 `/seedance-zodiac-beast-bust` 或 `/seedance-zodiac-beast-bust <星座名>`
- 用户描述「十二星座神兽机甲胸像 / 头雕 / 半身像 / 收藏雕像」类 Seedance 视频提示词
- 用户希望神兽机甲仍存在，但最终展示形态从全身兽形改为上半身收藏品

**不应触发**：

- 用户要完整神兽全身机甲 → 走 `seedance-zodiac-beast`
- 用户要可佩戴头盔 / 面具 → 走 `seedance-zodiac-beast-mask`
- 用户要盾牌、纹章、徽章浮雕 → 走 `seedance-zodiac-beast-crest`
- 用户要带环境底座的小场景 → 走 `seedance-zodiac-beast-diorama`

## 参数

`/seedance-zodiac-beast-bust [星座] [--expanded]`

- 不传参 → 从十二星座随机抽取，输出前标注「本次抽中：XX 座 × XX 神兽机甲胸像」
- 传入星座名（白羊座 / Aries / ♈ 等）→ 走对应胸像规格
- 默认 → 输出完整版提示词，扩写材质、铰链、锁扣、头部细节、肩甲、颈柱和底座结构
- `--compact` / 短版 / 紧凑版 / 压缩版 → 默认仍输出完整版；如用户或平台给出硬字符上限，只做结构保留型精简，保留镜头、时间轴主拍、主要部件五拍节奏、质量守恒和关键限制
- `--expanded` → 兼容旧用法，等同于默认完整版

## 主体外壳随机化规则

- 每次生成时，先锁定星座，再从该星座的「主体外壳特征」中随机取 2-3 个可见特征写入初始魔盒；不得跨星座借用外壳特征。
- 再随机追加 1 个工艺变化：斜切滑盖、环形旋闸、偏心齿环、透明观察窗、压铸编号、外露液压槽、嵌套套筒、微型散热鳍片、错层装甲瓣、细窄状态灯带。

- 避免所有主体都照抄「分瓣装甲、硬边棱面、八角锁环、镂空机芯窗」这一套固定外壳词；这些只能作为基础结构，不能替代星座专属外壳。

- **镜头**：补足连续手持观察感、45-60 厘米距离、主体占比、桌面留白、撞击反应震动、展开时小幅观察式微运镜和结尾呼吸式停留。

- **胸像识别**：强化头部、眼部透镜、颚部机构、角 / 鬃 / 钳 / 尾针 / 弓 / 瓶口 / 双鱼环等标志部件，但避免展开完整四肢或全身神兽。
- **时间轴**：每个阶段写清一个主动作组和必要物理结果；主要部件组保留抖动定位、受阻推进、回退 5%、再次推进、锁扣闭合，小件不重复完整五拍；前一组到位才触发下一组。
- **物理与音频**：拆开写零件来源、刚性连接、材质、反馈和声音；强调源开口保留为镂空痕迹，传力路径可见。
- **真实感**：补足体积守恒、承重点、接触阴影、制造痕迹、1-3mm 装配间隙、指纹灰尘、焦点呼吸和一致光源；LED 保持克制，不能变成魔法光效。
- **完整版长度**：默认输出完整版本；硬字符上限时只做结构保留型精简，必须保留镜头规则、主要部件五拍微循环、质量守恒、FRONT/01、材质细节、物理来源和关键限制，并把胸像收藏细节写完整。

## 注意事项

- 胸像必须有明确承重底座，避免模型生成漂浮头颅。
- 真实感优先检查承重点、接触阴影、装配缝和制造痕迹；不要只堆“精密金属”形容词。
- 视觉重点集中在头部、肩甲、胸甲和标志部件；四足、尾部、全身轮廓只可作为浮雕或背环元素。
- 结尾不要写新的英雄角度；写「保持同一连续手持观察关系与近景距离」。
- 禁用「顺滑、灵活、轻盈、魔法、玄幻」等污染词，使用「高延迟、重阻尼、强摩擦、错齿、逐级到位」。
