# Seedance 黄道十二神兽装甲体胸像提示词生成器（对应 /seedance-zodiac-beast-bust 命令）

重点是「桌面收藏雕像」：头部、角、鬃、钳、尾针、弓、瓶口、双鱼环等识别部件集中在上半身；下半身不完整展开，只以底座、胸甲、肩甲和结构颈柱承接。

**共享规则**：主体外壳特征表、外壳随机化规则、参数规则、共享输出段落（一镜头、二场景、三人物、六全局动作语义、阶段一/二、十关键限制通用前四句）和扩写规则的通用部分均定义在 `../_shared/zodiac-beast-variant-base.md`，本文件不再重复。

## 触发条件

**应触发**：

- 用户输入 `/seedance-zodiac-beast-bust` 或 `/seedance-zodiac-beast-bust <星座名>`
- 用户描述「十二星座神兽装甲体胸像 / 头雕 / 半身像 / 收藏雕像」类 Seedance 视频提示词
- 用户希望神兽装甲体仍存在，但最终展示形态从全身兽形改为上半身收藏品

**不应触发**：

- 用户要完整神兽全身装甲体 → 走 `seedance-zodiac-beast`
- 用户要可佩戴头盔 / 面具 → 走 `seedance-zodiac-beast-mask`

## 注意事项

- 胸像必须有明确承重底座，避免模型生成漂浮头颅。
- 真实感优先检查承重点、接触阴影、装配缝和制造痕迹；不要只堆"精密金属"形容词。
- 视觉重点集中在头部、肩甲、胸甲和标志部件；四足、尾部、全身轮廓只可作为浮雕或背环元素。
- 结尾不要写新的英雄角度；写「保持同一连续手持观察关系与近景距离」。
