# Seedance 国家倒推目标物可变形盒体提示词生成器（对应 /seedance-country-mechbox 命令）

为 Seedance 2.0 生成「国家 → 反推目标物 → 可变形盒体坠落 → 严格串行展开为目标物」的中文提示词。本 skill 的核心不是把画面做成完整国旗或地标拼贴，而是从国家的地理、气候、产业、交通文化、日常器物、材料质感、国旗色调、旗面标志性元素和大众可识别符号中反推出一个可物理展开的具体目标物。可变形盒体和最终目标物身上都必须出现该国家国旗的色调与图案元素，而且必须在视频中强可见、可读、可复核；这些元素必须转译成结构涂装、装甲分区、刻蚀线、窄灯带、浅浮雕、分缝节奏、透镜或零件轮廓，不能变成平面国旗贴纸、完整旗帜包覆或官方标识复刻。

目标物优先选择可承重、可展开、有明确结构部件来源的实体：车辆、船只、轨道交通、飞行器、工具设备、救援装备、港口 / 农业 / 工业装置、桌面收藏模型，也可以是从国家代表动物、地方特有动物或栖息地动物反推出来的结构动物 / 装甲体生物。动物目标必须是桌面结构收藏模型，不是真实生物复刻，不做血腥、捕猎或攻击人物画面。避免把国家简化成旗帜、地图轮廓、公众人物、真实机构标识、真实品牌 Logo、体育组织标志、攻击性装备或灾害事件。

提示词结构沿用项目内可变形盒体系列的稳定规则：镜头设定 → 场景 → 人物 → 主体 → 国旗可视化锁定 → 国家主题规则 → 全局动作语义 → 时间轴 → 结构与物理规则 → 真实感强化 → 关键限制。始终输出完整版提示词，不输出紧凑版、短版、压缩版、摘要版或骨架版。

## 触发条件

**应触发**：

- 用户输入 `/seedance-country-mechbox`、`/country-mechbox`、`/country-target-mechbox`、`/country2target`
- 用户要求「按国家倒推目标物」「根据国家生成可变形盒体目标物」「国家主题可变形盒体」
- 用户要求「按国家倒推动物」「国家代表动物可变形盒体」「国家主题结构动物 / 装甲体兽」
- 用户只给国家名，希望自动决定最终目标物
- 用户给出国家 + 大方向，如「日本 可变形盒体」「巴西 适合 TK 的目标物」「德国 工业感」

**不应触发**：

- 用户明确要求美国州主题 TikTok 内容包 → 走 `seedance-tiktok-us-mechbox`
- 用户明确要求十二星座、生肖、神兽、面具、胸像、纹章或微缩场景 → 走对应 zodiac skill
- 用户只要普通通用目标物可变形盒体，且国家不是主要输入 → 走 `seedance-mechbox`
- 静态图像提示词需求
- 用户要求真实机构标识、现实组织标识、真实品牌广告或商标精确复刻

## 参数

`/seedance-country-mechbox [国家] [可选目标方向]`

- **不传参** → 从映射表中随机选一个国家，并在输出前一行写「本次倒推：{国家} → {目标物}」。
- **只传国家** → 根据映射表或通用倒推规则自动决定目标物，并输出完整 Seedance 提示词。
- **国家 + 目标方向** → 保留用户的目标方向，但仍从国家反推材质、轮廓、分缝、铭牌、灯光和展开顺序。例如「日本 轨道交通」可生成 `precision Shinkansen inspection pod`。
- **国家 + 动物 / animal / 结构兽 / 代表动物** → 进入动物目标模式，优先从国家代表动物、地方特有动物或典型栖息地动物中选择目标，输出结构动物 / 装甲体生物，不输出真实活体动物。
- **`--compact` / 短版 / 紧凑版 / 压缩版** → 默认仍输出完整版提示词；如用户或平台给出硬字符上限，只做结构保留型精简，保留国家倒推、国旗结构化、阶段时间轴、质量守恒、物理来源和关键限制。

## 国旗色调与旗面元素转译规则

国旗色调和旗面元素是可变形盒体与目标物的必填设计来源，必须同时出现在两者表面或结构中，但不能直接把旗帜平铺到盒面或目标物表面。生成时按以下规则处理：

1. **先取主辅色**：从指定国家国旗中提取 2-4 个主辅色，并拆成“盒体阶段配色”和“目标物阶段配色”两套具体承载。盒体阶段优先分配为装甲主色、边缘副色、状态灯色或铭牌边框色；目标物阶段优先分配为外壳主色、结构骨架色、透镜色、功能灯色或关键部件色。主色必须覆盖盒体与目标物的可见大面装甲，副色进入分缝边缘、铰链护片、内腔骨架、窄灯带和铭牌边框，不要形成完整旗帜比例。
2. **再取旗面元素**：每次至少选择 1 个可结构化旗面元素，同时落到盒体和最终目标物。星、太阳、月牙、圆盘、十字、斜十字、条纹、三角形、叶片、纹章、动物、工具形或复杂几何符号都必须结构抽象化；若该国旗只有条纹或色块，也要把条纹节奏、色块比例或色带边界转成功能分缝与装甲分区。可转译为浅浮雕刻线、联动轮护环、圆形透镜、放射状散热片、星形螺栓阵列、月牙形锁止弧、十字形加强筋、条纹式分缝、三角护板、叶脉状散热槽、几何铭牌或动物轮廓的结构铭牌。若旗面元素带有攻击性联想，只保留中性的弧线、长条、圆盘、交叉骨架或几何轮廓。
3. **避免官方复刻**：可以使用“来自某国旗的色调和几何识别感”，但不要生成完整国旗、官方徽章、国徽、军徽、政党符号、机构标志、精确纹章或可直接替代官方标识的图案。
4. **与目标物绑定**：旗面元素不能孤立装饰，必须服务于目标物结构。例如太阳元素转成车头圆形透镜和放射散热片，枫叶转成雪地车护板叶脉槽，星群转成舱门铆钉阵列，月牙转成船首锁止弧，十字转成缆车舱加强筋，条纹转成装甲分缝节奏。
5. **结构盒体与目标物一致**：初始结构盒体和最终目标物要共享同一套国旗色调与旗面元素逻辑，但展开后颜色权重可以重新分配。盒体阶段必须以清楚的色块、窄线和浮雕预示，目标物阶段必须把这些色彩和图案元素释放到可读的功能部件上；不得只在盒体出现国旗元素，也不得只在最终目标物出现国旗元素。
6. **位置必须具体**：旗面图案元素必须分别落在盒体和目标物的明确结构承载面上，例如盒体顶盖分缝、侧边铰链护片、前端传动窗边框，以及目标物车头透镜、船首护环、翼根铰链、动物头甲、脊柱护片、履带侧裙或尾部平衡架。不要只写“带有国旗元素”，不要只给一个总位置。
7. **强可见而非低权重**：不能只写低权重铭牌、细小刻线、暗色窄灯带或隐藏内腔。盒体阶段至少写出一处正面或顶盖可见的国旗色装甲分区，以及一处旗面元素结构浮雕 / 透镜 / 螺栓阵列 / 分缝图案；目标物阶段至少写出一处正面、侧面或头部可见的大面国旗色装甲分区，以及一处从盒体延续来的旗面元素精密结构。镜头在初始触发/落桌碰撞阶段和终态稳定阶段都必须能读到这些元素。
8. **可视化验收**：生成最终 prompt 前做一次验收：如果删掉国家名称、铭牌文字和说明文字后，观众仍不能从盒体与最终目标物的颜色组合和结构化旗面元素中识别该国旗来源，就必须加强国旗色块面积、对比度、位置和旗面元素形状。

## 目标物选择原则

- **可物理展开优先**：有轮组、履带、船体、车鼻、舱门、支撑臂、传感器、桅杆、缆索、支架、浮筒等部件的目标更稳定。动物类目标则优先选择头甲、颚部、眼部透镜、脊柱节段、四肢液压杆、翼骨、尾部平衡架、鳍片、爪部或甲壳可以清楚分段展开的对象。
- **动物目标结构化**：动物可以作为最终目标，但必须写成结构动物 / 装甲体生物 / 桌面收藏兽。外观来自动物的轮廓和部件逻辑，材质来自结构装甲、铰链、套筒、透镜、液压杆和支架，不表现真实皮毛、血肉、捕猎、撕咬或攻击人物。
- **国家感来自结构，不来自贴图**：国旗色调、旗面元素、纹样和铭牌必须融入装甲分缝、浮雕刻线、工业涂装、细窄灯带、透镜或材料质感。可变形盒体和目标物都必须使用国旗主辅色，并且都必须出现至少一个高可见结构化旗面元素，但不能把完整国旗当作贴图。国旗元素不能只停留在暗部、内腔、小铭牌或低权重刻线。
- **避免过度刻板印象**：不要把国家只简化成食物、服饰、旗帜或单一地标。可以用这些作为次级材质线索，但目标物仍应是封闭初始实体。
- **避免风险目标**：默认不生成攻击性装备、真实对抗装备、灾害事故、公众人物、真实宗教圣物或高风险现实场景。动物目标不生成血腥、受伤、捕食、斗兽或惊吓人物的画面。
- **品牌与公共标识 anti-bias**：真实品牌、球队、大学、奥运标识、公共机构标识只作为禁用项，不作为画面生成目标。

## 常见失败修复

- **像国旗贴纸盒**：保留国旗主辅色和旗面图案元素，但删除平面旗帜贴纸、完整旗帜包覆、地图轮廓、旅游图案，改为装甲分区、工业涂装、刻蚀铭牌、窄灯带、材料拼接和目标物结构来源，并指定盒体与目标物上的具体承载位置。
- **国家感太弱**：从地理、产业、交通、材料、日常器物、国旗色调和旗面标志性元素中补 2-3 条线索，并让它们同时影响可变形盒体和最终目标物的类型、外壳轮廓、分缝、涂装和材质；补充盒体承载位置和目标物承载位置，避免只在其中一方出现国家元素。
- **视频看不出国旗元素**：把国旗身份从细节暗示升级为强可见装甲设计。盒体必须在顶盖 / 正面 / 侧边有国旗主辅色大面装甲分区和结构化旗面元素；目标物必须在车头 / 船首 / 头甲 / 翼根 / 履带侧裙 / 侧舱门等主识别面继承同一元素。删除“低权重、小型、暗部、隐藏、微弱”等描述，改为“清楚可见、正面可读、末帧可复核”。
- **目标物不清楚**：优先换成可物理展开的实体，如救援车、巡检船、轨道车、缆车舱、港口穿梭车、农业设备；动物模式下优先换成有清楚头甲、四肢 / 翅膀 / 尾部和眼部透镜的结构动物。
- **动物太像真实生物**：补结构动物、桌面装甲体收藏模型、分段装甲、液压四肢、透镜眼、脊柱节段和尾部平衡架，删除皮毛写实、血肉、捕猎、撕咬和攻击人物描述。
- **动作太顺滑**：补高延迟、重阻尼、强摩擦、阶段性停滞、轻微错齿和五拍微循环。
- **零件凭空出现**：在主体和时间轴里明确源开口、铰链槽、滑轨、套筒口和保留的镂空痕迹。
- **触发真实标识风险**：删真实机构标识、组织标志、球队标识、大学标识、真实品牌 Logo，改用替代工业铭牌。
