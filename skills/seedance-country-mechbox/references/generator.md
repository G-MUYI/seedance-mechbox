# Seedance 国家倒推目标物机械魔盒提示词生成器（对应 /seedance-country-mechbox 命令）

为 Seedance 2.0 生成「国家 → 反推目标物 → 机械魔盒坠落 → 严格串行展开为目标物」的中文提示词。本 skill 的核心不是让画面出现国旗或地标拼贴，而是从国家的地理、气候、产业、交通文化、日常器物、材料质感和大众可识别符号中反推出一个可机械展开的具体目标物。

目标物优先选择可承重、可展开、有明确机械部件来源的实体：车辆、船只、轨道交通、飞行器、工具设备、救援装备、港口 / 农业 / 工业装置、桌面收藏模型，也可以是从国家代表动物、地方特有动物或栖息地动物反推出来的机械动物 / 机甲生物。动物目标必须是桌面机械收藏模型，不是真实生物复刻，不做血腥、捕猎或攻击人物画面。避免把国家简化成旗帜、地图轮廓、政治人物、官方徽章、真实品牌 Logo、体育队徽、战争武器或灾害事件。

提示词结构沿用项目内机械魔盒系列的稳定规则：镜头设定 → 场景 → 人物 → 主体 → 国家主题规则 → 全局动作语义 → 时间轴 → 机械与物理规则 → 真实感强化 → 关键限制。始终输出完整版提示词，不输出紧凑版、短版、压缩版、摘要版或骨架版。

## 触发条件

**应触发**：

- 用户输入 `/seedance-country-mechbox`、`/country-mechbox`、`/country-target-mechbox`、`/country2target`
- 用户要求「按国家倒推目标物」「根据国家生成机械魔盒目标物」「国家主题机械魔盒」
- 用户要求「按国家倒推动物」「国家代表动物机械魔盒」「国家主题机械动物 / 机甲兽」
- 用户只给国家名，希望自动决定最终目标物
- 用户给出国家 + 大方向，如「日本 机械魔盒」「巴西 适合 TK 的目标物」「德国 工业感」

**不应触发**：

- 用户明确要求美国州主题 TikTok 内容包 → 走 `seedance-tiktok-us-mechbox`
- 用户明确要求十二星座、生肖、神兽、面具、胸像、纹章或微缩场景 → 走对应 zodiac skill
- 用户只要普通通用目标物机械魔盒，且国家不是主要输入 → 走 `seedance-mechbox`
- 静态图像提示词需求
- 用户要求真实国徽、真实军徽、真实品牌广告或商标精确复刻

## 参数

`/seedance-country-mechbox [国家] [可选目标方向]`

- **不传参** → 从映射表中随机选一个国家，并在输出前一行写「本次倒推：{国家} → {目标物}」。
- **只传国家** → 根据映射表或通用倒推规则自动决定目标物，并输出完整 Seedance 提示词。
- **国家 + 目标方向** → 保留用户的目标方向，但仍从国家反推材质、轮廓、分缝、铭牌、灯光和展开顺序。例如「日本 轨道交通」可生成 `precision Shinkansen inspection pod`。
- **国家 + 动物 / animal / 机械兽 / 代表动物** → 进入动物目标模式，优先从国家代表动物、地方特有动物或典型栖息地动物中选择目标，输出机械动物 / 机甲生物，不输出真实活体动物。
- **`--compact` / 短版 / 紧凑版 / 压缩版** → 已废弃，不改变输出长度；仍输出完整版提示词。

## 未列国家的通用倒推规则

若用户指定的国家不在表中，按以下顺序反推，不要停止询问：

1. 提取 2-3 个稳定、非敏感的国家来源：地理气候、产业、交通、建筑材料、日常器物、港口 / 农业 / 山地 / 沙漠 / 冰雪 / 河流 / 代表动物 / 特有动物 / 栖息地动物等。
2. 优先选择能机械展开的实体目标：车辆、船、列车、缆车、救援设备、农用设备、港口穿梭车、测绘装置、桌面仪器。若用户要求动物或该国家动物线索更强，可选择机械动物、机甲鸟、机械鱼、机械昆虫、四足巡护兽或水陆两栖机甲。
3. 让目标物具备清晰主轴、承重点、前端识别面、侧面关键部件、灯光或透镜细节。动物类目标必须具备可追溯的头甲、脊柱、四肢 / 翅膀 / 鳍、尾部、眼部透镜和承重支点。
4. 从目标物反推初始魔盒：主轮廓、分缝布局、源开口、触发机构、前端机芯窗、铭牌、材质与灯光。
5. 铭牌使用国家英文或常用缩写 + 类型编号，如 `PERU/ANDES-01`、`POLAND/RAIL-01`、`QATAR/DESERT-01`。不要使用真实国徽、官方标志、政党符号或军徽。

## 目标物选择原则

- **可机械展开优先**：有轮组、履带、船体、车鼻、舱门、机械臂、传感器、桅杆、缆索、支架、浮筒等部件的目标更稳定。动物类目标则优先选择头甲、颚部、眼部透镜、脊柱节段、四肢液压杆、翼骨、尾部平衡架、鳍片、爪部或甲壳可以清楚分段展开的对象。
- **动物目标机械化**：动物可以作为最终目标，但必须写成机械动物 / 机甲生物 / 桌面收藏兽。外观来自动物的轮廓和部件逻辑，材质来自机械装甲、铰链、套筒、透镜、液压杆和支架，不表现真实皮毛、血肉、捕猎、撕咬或攻击人物。
- **国家感来自结构，不来自贴图**：颜色、纹样和铭牌必须融入装甲分缝、浮雕刻线、工业涂装、细窄灯带或材料质感。
- **避免过度刻板印象**：不要把国家只简化成食物、服饰、旗帜或单一地标。可以用这些作为次级材质线索，但目标物仍应是机械实体。
- **避免风险目标**：默认不生成坦克、导弹、军舰、枪械、真实军事装备、灾害事故、政治人物、真实宗教圣物或冲突场景。动物目标不生成血腥、受伤、捕食、斗兽或惊吓人物的画面。

## 常见失败修复

- **像国旗贴纸盒**：删除旗帜贴纸、地图轮廓、旅游图案，改为工业涂装、刻蚀铭牌、材料拼接和目标物结构来源。
- **国家感太弱**：从地理、产业、交通、材料和日常器物中补 2-3 条线索，并让它们影响目标物类型、外壳轮廓和材质。
- **目标物不清楚**：优先换成可机械展开的实体，如救援车、巡检船、轨道车、缆车舱、港口穿梭车、农业设备；动物模式下优先换成有清楚头甲、四肢 / 翅膀 / 尾部和眼部透镜的机械动物。

- **零件凭空出现**：在主体和时间轴里明确源开口、铰链槽、滑轨、套筒口和保留的镂空痕迹。
- **触发真实标识风险**：删真实国徽、军徽、政府标识、球队徽章、大学校徽、真实品牌 Logo，改用替代工业铭牌。
