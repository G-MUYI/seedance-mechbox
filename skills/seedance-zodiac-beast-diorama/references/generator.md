# Seedance 黄道十二神兽装甲体微缩展台提示词生成器（对应 /seedance-zodiac-beast-diorama 命令）

为 Seedance 2.0 生成「按下按钮 → 可变形盒体坠落 → 严格串行展开为黄道十二星座神兽装甲体微缩展台 / 结构小场景」的中文提示词。本 skill 复用 `seedance-zodiac-beast` 的神兽装甲体设定，但最终物体不是单个神兽，而是由结构底座、背板、支架、铭牌、星座刻印环和小比例神兽装甲体组成的桌面收藏展台。

重点是「微缩展示装置」：场景必须是盒体自身物理展开出来的桌面物件，不生成真实远景环境，不切到大场面。所有地台、背板、支架、神兽主体和装饰结构都必须从盒体现有源开口可视追溯。

**共享规则**：主体外壳特征表、外壳随机化规则、参数规则、共享输出段落和扩写规则的通用部分均定义在 `../_shared/zodiac-beast-variant-base.md`，本文件不再重复。

## 触发条件

**应触发**：

- 用户输入 `/seedance-zodiac-beast-diorama` 或 `/seedance-zodiac-beast-diorama <星座名>`
- 用户描述「星座神兽装甲体展台 / 微缩场景 / 结构地台 / 收藏展示盒」
- 用户想保留神兽装甲体主题，但最终展示物体带底座、背景板和场景结构

**不应触发**：

- 用户要胸像 / 头雕 → 走 `seedance-zodiac-beast-bust`
- 用户要面具 / 头盔 → 走 `seedance-zodiac-beast-mask`
- 用户要纹章盾牌 → 走 `seedance-zodiac-beast-crest`
- 用户要完整单体神兽 → 走 `seedance-zodiac-beast`

## 变体专属扩写补充

在共享扩写规则基础上，微缩展台变体额外要求：

- **主体部件清单**：写清地台层板、背板、展示臂、支架、铭牌槽、星座刻印环、小比例神兽主体和 FRONT/01 传动窗。
- **展台识别**：强化地台、背板、灯带、支撑臂和小比例神兽姿态；所有环境感都来自盒体展开出的精密结构，避免真实大场景。
- **完整版长度**：把微缩展台细节写完整。

## 注意事项

- 展台不是外部场景；所有"环境感"都必须由盒体展开出的地台、背板、支架和灯带承担。
- 真实感优先检查地台接触点、背板承重、展示臂来源、层板厚度、接触阴影和制造痕迹。
- 神兽主体可以是小比例全身、半身或动态姿态，但必须被支架 / 地台结构承托。
- 不写沙尘、烟雾、魔法光阵、宇宙背景等大场面元素。
- 最终画面应像桌面收藏展示盒，不像切换到一座真实建筑或自然场景。
