# Seedance 黄道十二神兽机甲微缩展台提示词生成器（对应 /seedance-zodiac-beast-diorama 命令）

为 Seedance 2.0 生成「按下按钮 → 机械魔盒坠落 → 严格串行展开为黄道十二星座神兽机甲微缩展台 / 机械小场景」的中文提示词。本 skill 复用 `seedance-zodiac-beast` 的神兽机甲设定，但最终物体不是单个神兽，而是由机械底座、背板、支架、铭牌、星座刻印环和小比例神兽机甲组成的桌面收藏展台。

重点是「微缩展示装置」：场景必须是盒体自身机械展开出来的桌面物件，不生成真实远景环境，不切到大场面。所有地台、背板、支架、神兽主体和装饰结构都必须从魔盒现有源开口可视追溯。

## 触发条件

**应触发**：

- 用户输入 `/seedance-zodiac-beast-diorama` 或 `/seedance-zodiac-beast-diorama <星座名>`
- 用户描述「星座神兽机甲展台 / 微缩场景 / 机械地台 / 收藏展示盒」
- 用户想保留神兽机甲主题，但最终展示物体带底座、背景板和场景结构

**不应触发**：

- 用户要胸像 / 头雕 → 走 `seedance-zodiac-beast-bust`
- 用户要面具 / 头盔 → 走 `seedance-zodiac-beast-mask`
- 用户要纹章盾牌 → 走 `seedance-zodiac-beast-crest`
- 用户要完整单体神兽 → 走 `seedance-zodiac-beast`

## 参数

`/seedance-zodiac-beast-diorama [星座] [--expanded]`

- 不传参 → 随机抽取星座，输出前标注「本次抽中：XX 座 × XX 神兽机甲微缩展台」
- 传入星座名 → 走对应微缩展台规格
- 默认 → 输出完整版提示词，扩写地台层级、背板机械纹理、展示臂、铭牌灯带和神兽姿态
- `--compact` / 短版 / 紧凑版 / 压缩版 → 已废弃，不改变输出长度；仍输出完整版提示词
- `--expanded` → 兼容旧用法，等同于默认完整版

## 主体外壳随机化规则

- 每次生成时，先锁定星座，再从该星座的「主体外壳特征」中随机取 2-3 个可见特征写入初始魔盒；不得跨星座借用外壳特征。
- 再随机追加 1 个工艺变化：斜切滑盖、环形旋闸、偏心齿环、透明观察窗、压铸编号、外露液压槽、嵌套套筒、微型散热鳍片、错层装甲瓣、细窄状态灯带。
- 外壳描述必须让 0-1.8 秒的盒体第一眼就有星座专属气质，但仍保持纯机械魔盒，不提前露出完整展台、完整小场景或完整神兽主体。
- 避免所有主体都照抄「分瓣装甲、硬边棱面、八角锁环、镂空机芯窗」这一套固定外壳词；这些只能作为基础结构，不能替代星座专属外壳。

## 默认完整版扩写规则

默认输出时，不要只输出上方骨架；按以下规则扩写到完整版：

- **镜头**：补足连续手持观察感、45-60 厘米距离、主体占比、桌面留白、撞击反应震动、展开时小幅观察式微运镜和结尾呼吸式停留。
- **主体**：扩写高密度、重型、精密机械结构；必须写入当前星座的{主体外壳特征}，并随机选择 1 个工艺变化，避免每次都使用同一套固定外壳；写清地台层板、背板、展示臂、支架、铭牌槽、星座刻印环、小比例神兽主体和 FRONT/01 机芯窗。
- **展台识别**：强化地台、背板、灯带、支撑臂和小比例神兽姿态；所有环境感都来自盒体展开出的机械结构，避免真实大场景。
- **时间轴**：每个阶段写成多句，说明部件先抖动定位、受阻推进、回退 5%、再次推进、锁扣闭合；前一组到位才触发下一组。
- **物理与音频**：拆开写零件来源、刚性连接、材质、反馈和声音；强调源开口保留为镂空痕迹，传力路径可见。
- **真实感**：补足体积守恒、承重点、接触阴影、制造痕迹、1-3mm 装配间隙、指纹灰尘、焦点呼吸和一致光源；LED 保持克制，不能变成魔法光效。

## 注意事项

- 展台不是外部场景；所有“环境感”都必须由盒体展开出的地台、背板、支架和灯带承担。
- 真实感优先检查地台接触点、背板承重、展示臂来源、层板厚度、接触阴影和制造痕迹。
- 神兽主体可以是小比例全身、半身或动态姿态，但必须被支架 / 地台机械承托。
- 不写沙尘、烟雾、魔法光阵、宇宙背景等大场面元素。
- 最终画面应像桌面收藏展示盒，不像切换到一座真实建筑或自然场景。
