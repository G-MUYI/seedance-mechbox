# Seedance 黄道十二神兽机甲变形提示词生成器（对应 /seedance-zodiac-beast 命令）

为字节跳动 Seedance 2.0 视频模型生成「按下按钮 → 魔盒坠落 → 串行机械展开为黄道十二星座对应神兽机甲」的中文提示词。本 skill 与 `seedance-mechbox`（豪车系列）并行，把目标物从车型替换为神兽（公羊、巨蟹、毒蝎、半人马、双鱼……），机械语言更生物化、更具仪式感、收藏品溢价更高。

提示词结构沿用 Seedance 2.0 偏好的「镜头 → 主体 → 时间轴 → 机械规则 → 关键限制」编排。始终输出完整版提示词（≈ 2800 中文字符或更完整），主干用正向描述，仅保留四类必要负向项；不输出紧凑版、短版、压缩版、摘要版或骨架版。

## 触发条件

**应触发**：

- 用户输入 `/seedance-zodiac-beast` 或 `/seedance-zodiac-beast <星座名>`
- 用户输入 `/zodiac-beast <星座名>`
- 用户描述「机械盒掉下来变成 XX 星座神兽 / 机甲」类视频脚本需求

**不应触发**：

- 用户明确指定车型 / 飞机 / 战舰等非神兽目标 → 走 `seedance-mechbox`
- 与机械变形无关的通用 Seedance 提示词需求
- 用户要求其他视频模型（Sora / Kling / Veo / Runway 等）的提示词

## 参数

`/seedance-zodiac-beast [星座] [--expanded]`

- **不传参** → 从十二星座中随机抽一个，并在输出前一行告知「本次抽中：XX 座 × XX 神兽」
- **传入星座名**（白羊座 / Aries / ♈ 等） → 走对应神兽规格
- **默认** → 输出完整版提示词（≈ 2800 中文字符），按「默认完整版扩写规则」补足材质、机构、动作反馈与时间轴细节
- **`--compact` / 短版 / 紧凑版 / 压缩版** → 已废弃，不改变输出长度；仍输出完整版提示词，保留完整镜头规则、时间轴、五拍节奏、质量守恒、材质细节和关键限制
- **`--expanded` 标志** → 兼容旧用法，等同于默认完整版，不再是额外开关

## 执行步骤

1. **解析输入**：星座名 → 查表确定 {神兽} {气质} {符号} {主铭牌} {主色调}；不传参 → 随机抽一个并在第一行标注「本次抽中：XX 座 × XX 神兽」
