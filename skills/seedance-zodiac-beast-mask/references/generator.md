# Seedance 黄道十二神兽装甲体面具提示词生成器（对应 /seedance-zodiac-beast-mask 命令）

为 Seedance 2.0 生成「按下按钮 → 可变形盒体坠落 → 严格串行展开为黄道十二星座神兽装甲体面具 / 头盔」的中文提示词。本 skill 复用 `seedance-zodiac-beast` 的神兽气质，但最终物体是桌面展示用结构面具，不是完整神兽、不是真人佩戴，也不是普通角色头盔。

面具形态强调：正面轮廓、眼部透镜、颚部机构、耳侧铰链、额冠 / 角 / 鬃 / 钳 / 尾针 / 弓形冠 / 瓶口冠 / 双鱼环等识别部件。必须有展示支架或后部锁环承重。

## 触发条件

**应触发**：

- 用户输入 `/seedance-zodiac-beast-mask` 或 `/seedance-zodiac-beast-mask <星座名>`
- 用户描述「星座神兽装甲体面具 / 头盔 / 结构假面 / 展示面甲」
- 用户想保留神兽装甲体主题，但最终展示物体是可陈列的面具形态

**不应触发**：

- 用户要胸像 / 头雕 → 走 `seedance-zodiac-beast-bust`
- 用户要盾牌纹章 → 走 `seedance-zodiac-beast-crest`
- 用户要微缩场景 → 走 `seedance-zodiac-beast-diorama`
- 用户要全身神兽 → 走 `seedance-zodiac-beast`

## 参数

`/seedance-zodiac-beast-mask [星座] [--expanded]`

- 不传参 → 随机抽取一个星座，输出前标注「本次抽中：XX 座 × XX 神兽装甲体面具」
- 传入星座名 → 走对应面具规格
- 默认 → 输出完整版提示词，扩写内衬、脸颊护板、锁扣、透镜、后部展示环和面甲分缝
- `--compact` / 短版 / 紧凑版 / 压缩版 → 默认仍输出完整版；如用户或平台给出硬字符上限，只做结构保留型精简，保留镜头、时间轴主拍、主要部件五拍节奏、质量守恒和关键限制
- `--expanded` → 兼容旧用法，等同于默认完整版

## 主体外壳随机化规则

- 每次生成时，先锁定星座，再从该星座的「主体外壳特征」中随机取 2-3 个可见特征写入初始盒体；不得跨星座借用外壳特征。
- 再随机追加 1 个工艺变化：斜切滑盖、环形旋闸、偏心齿环、透明观察窗、压铸编号、外露液压槽、嵌套套筒、微型散热鳍片、错层装甲瓣、细窄状态灯带。
- 外壳描述必须让初始触发和落桌碰撞阶段的盒体第一眼就有星座专属气质，但仍保持纯可变形盒体，不提前露出完整面具、完整额冠或完整标志部件。
- 避免所有主体都照抄「分瓣装甲、硬边棱面、八角锁环、镂空传动窗」这一套固定外壳词；这些只能作为基础结构，不能替代星座专属外壳。

## 默认完整版扩写规则

默认输出时，不要只输出上方骨架；按以下规则扩写到完整版：

- **镜头**：补足连续手持观察感、45-60 厘米距离、主体占比、桌面留白、撞击反应震动、展开时小幅观察式微运镜、结尾呼吸式停留和锁定后轻微小动作。
- **主体**：扩写高密度、重型、精密结构；必须写入当前星座的{主体外壳特征}，并随机选择 1 个工艺变化，避免每次都使用同一套固定外壳；写清展示支架、后部锁环、面甲主板、眼部透镜、颚部护板、脸颊侧甲、耳侧铰链、额冠和 FRONT/01 传动窗；参考图模式下让初始盒材质继承目标参考图材质。
- **面具识别**：强化眼部、额冠、脸颊、颚部和后环上的角 / 鬃 / 钳 / 尾针 / 弓形冠 / 瓶口冠 / 双鱼环等部件，但避免真人佩戴和完整神兽全身。
- **时间轴**：每个阶段写清一个主动作组和必要物理结果；主要部件组保留抖动定位、受阻推进、回退 5%、再次推进、锁扣闭合，小件不重复完整五拍；前一组到位才触发下一组。
- **物理与音频**：拆开写零件来源、刚性连接、材质、反馈和声音；强调源开口保留为镂空痕迹，传力路径可见。
- **真实感**：补足体积守恒、承重点、接触阴影、制造痕迹、1-3mm 装配间隙、指纹灰尘、焦点呼吸和一致光源；LED 保持克制，不能变成魔法光效。
- **完整版长度**：默认输出完整版本；硬字符上限时只做结构保留型精简，必须保留镜头规则、主要部件五拍微循环、质量守恒、FRONT/01、材质细节、物理来源和关键限制，并把面具展示细节写完整。

## 注意事项

- 必须写展示支架或后部锁环，否则模型容易生成漂浮面具。
- 真实感优先检查展示支架、后部锁环、透镜厚度、装配缝、接触阴影和制造痕迹。
- 面具正面从初始画面由 FRONT/01 锚定，最终不要换成正脸特写。
- 面具可以有内衬骨架，但不出现真人头部、脖子或佩戴动作。
- 标志部件集中在额冠、脸颊、颚部和后环，不生成完整四肢。
