# Seedance 机械魔盒变形提示词生成器（对应 /seedance-mechbox 命令）

为字节跳动 Seedance 2.0 视频模型生成「按下按钮 → 魔盒坠落 → 串行机械展开为目标物」的中文提示词。本 skill 以「十二星座 × 豪车」系列为主，保留飞机 / 机甲 / 战舰等多目标扩展能力。提示词结构按 Seedance 2.0 偏好的「镜头 → 主体 → 时间轴 → 机械规则 → 关键限制」编排，始终输出完整版提示词，主干用正向描述，仅保留少量必要负向项；不输出紧凑版、短版、压缩版、摘要版或骨架版。

## 触发条件

**应触发**：

- 用户输入 `/seedance-mechbox` 或 `/seedance-mechbox <星座名>`
- 用户输入 `/seedance-mechbox <非星座目标物>`（如「飞机」「机甲」「战舰」「Bugatti Chiron」等）
- 用户描述「机械盒掉下来变形成 XX」类视频脚本需求

**不应触发**：

- 与机械变形无关的通用 Seedance 提示词需求
- 用户要求其他视频模型（Sora / Kling / Veo / Runway 等）的提示词
- 静态图像提示词需求

## 参数

`/seedance-mechbox [目标]`

- **不传参** → 从十二星座中随机抽一个，使用对应车型，并在输出前一行告知用户「本次抽中：XX 座 × XX 车型」
- **传入星座名**（白羊座 / Aries / ♈ 等） → 走星座系列模式，自动匹配对应车型与气质
- **传入非星座目标物**（飞机 / 机甲 / 战舰 / 具体车型名等） → 走通用模式，跳过星座规则段，按目标物反推魔盒初始状态
- **`--compact` / 短版 / 紧凑版 / 压缩版** → 已废弃，不改变输出长度；仍输出完整版提示词，保留完整镜头规则、时间轴、五拍节奏、质量守恒、材质细节和关键限制

## 执行步骤

按顺序执行：

1. **解析输入**：判断走星座模式还是通用目标模式。星座模式下查表确定 {车型} {气质} {符号} {主铭牌}；通用模式下从目标物反推主轴 / 承重点 / 展开方向 / 关键部件来源。
2. **反推初始魔盒状态**：不要套固定主体描述。先从最终物体反推「主轴、承重点、展开方向、关键部件来源」，再生成有逻辑的初始硬边机械盒。参考初始化魔盒图片时只提炼共性原子，不复刻单个造型：
   - 实体感：掌心玩具 / 可动手办级真实实体，重量与厚度可信
   - 拼合：分瓣装甲壳 + 硬边棱面，环形 / 纵横 / 节段主分缝
   - 顶部：嵌入式圆形启动键 + 六角或八角锁环
   - 边角：四角防撞滚花角块或螺栓加强框，装甲交界布六角螺栓阵列
   - 螺栓增强：部分螺栓头内嵌微光 LED 状态点，与主灯同色
   - 正前端：「外框 + 镂空机芯窗」结构，凹窗中可见层叠齿轮、十字 / X 跨面连杆与曲柄、套筒、轴承环、弹簧液压柱；中心嵌大轴承或星形主齿作视觉锚点
   - 表面对比：装甲片哑光磨砂 / 拉丝 / 碳纤维主面 + 抛光金属骨架 / 锁环 / 机芯框，形成硬框 + 哑光面板的工业层级
   - 工业涂装：可在装甲带 / 棱边引入识别色块、对角警戒条带、序列号铭牌、刻蚀图腾、铭牌灯带（机械产品涂装，非贴纸）
   - 其余分布：少量狭长状态灯条、散热栅格、卡扣式模块插槽、可拆面板、阶梯层叠装甲带、清晰源开口

   星座模式下，魔盒造型语言、展开节奏、灯光气质都需与该星座 × 车型一致。通用模式参考：
   - 楔形超跑（Revuelto / SF90 / Artura / 765LT / Evija）→ 低矮楔形截角多面体或压扁圆盘壳，FRONT 面密集三段滑轨，装甲瓣片呈放射切线
   - 长车头豪华轿（Continental GT / S-Class / DB12）→ 厚实长向多面体或分瓣球壳，前部多段套筒，侧面饱满但保留硬边分缝
   - 精密赛道车（911 GT3 / 911 Dakar）→ 紧凑中心对称多面体，顶部八角锁环与赤道分缝清楚，分缝精度高
   - 方正硬派（G63）→ 倒角立方体或硬边装甲箱，棱角直角，角块、铆钉、橙色窄灯和卡扣密集，常配对角警戒条带
   - 飞机 / 战斗机 → 扁平箭头折面盒，纵向套筒+两侧长条铰链槽+底部起落架源开口

   - 海船 / 战舰 → 长条棱柱船坞盒或模块锁链方块，底部龙骨滑轨+两侧舷板折线+前端船首套筒
   - 阶梯精密 / 仪表 → 阶梯多层方块或截顶锥壳，正面镂空机芯窗 + 跨面 X 连杆 + 大轴承中心，常用抛光铬 / 黄铜配色
3. **填入模板**：按下文「输出格式」编排，确保镜头 / 主体 / 时间轴 / 机械规则 / 关键限制五大段全部齐全；星座模式必须包含「十二星座规则」段。

## 注意事项

**硬规则（不可妥协，违反任一条都会复现已知失败模式）**：

1. **主干用正向描述，负向项仅保留四类**：根据 Seedance 2.0 实践，提示词太长、否定太密会让后半段冲淡前半段意图。本模板把镜头/动作/物理全部用正向描述（「保持」「允许」「呈现」），仅在「关键限制」段保留 4 条核心负向：不切镜不重置机位、不凭空生长、不魔法变形、不出现字幕 UI 道具音乐。
2. **镜头规则强调「连续手持观察感」而非「固定不动」**：旧版本反复写「不要推近」「不要拉远」「不要横摇」，模型容易理解为三脚架静止。新版正向描述允许的小幅运镜（前后位移、左右漂移、俯仰修正、弧线观察），并给镜头分配时间轴动作（按下时跟随、撞击时反应性震动、展开时观察式微运镜、结尾呼吸式停留）。
3. **动作语义用具体词汇替代抽象形容词**：禁用「流畅、顺滑、灵活、轻快、丝滑、敏捷、利落、飘逸」等触发轻盈感的词；统一用「高延迟、重阻尼、强摩擦、阶段性停滞、轻微错齿、传动迟滞、沉重反馈、逐级到位、最终扣合」+ 五拍微循环（启动轻抖 → 推进 60% → 短暂停滞 → 回退 5% → 再次推进 → 最终到位）。
4. **画面距离与构图明确写出数值**：仅写「3/4 侧前」「英雄角度」会让模型贴脸特写。必须写镜头距离 45-60cm、主体占画面 45-60% 高度 / 50-65% 宽度、四周保留桌面留白、最终能看见完整车头 + 前轮 + 一侧车身 + 部分尾部。
5. **结尾不能描述新的「最终镜头角度」**：「最终停在轻微俯视 3/4 侧前英雄角度」这类句子会让模型把最后 1 秒解读为换镜头。必须写「保持原有机位 / 距离 / 构图，最终完成感来自机械展开后的姿态、灯光、结构到位，而非更换镜头」。
6. **朝向必须从第 0 秒锚定**：仅在结尾约束朝向会导致变形过程随意定向，最后一帧跳切。从第 0 秒就设置「FRONT / 01」可见前端面，最终必须由该面演化出车头。
7. **变形严格串行，禁止同步展开**：一拍只动一个部位，前一步锁定后才触发下一步，否则丢失机械高延迟卡顿真实感。
8. **质量守恒强制要求**：所有新零件必须可视追溯到盒体已有外壳的源开口、铰链、套筒、滑轨；零件被顶出时源开口在画面中保留为镂空痕迹。
9. **真实感必须落在物理证据上**：必须写接触阴影、承重点、体积守恒、制造痕迹、装配缝、透镜厚度和一致光源；不要只堆「真实、精密、金属」形容词。
10. **星座模式下符号必须结构化**：以金属蚀刻、浮雕刻线、微发光铭牌、细窄灯带、机械表盘形式分布在顶盖 / 侧边 / 环形外框上，与机械结构自然融合，禁止贴纸式 / 漂浮式 / 玄幻占星风。
11. **品牌名必须配 anti-bias 约束**：单写品牌名会被训练数据的「招牌视角」先验拉走。必须配显式机位描述 + 前端具象元素罗列 + 反尾部权重提示（「尾部仅作为远端结构，不抢视觉中心」）。
12. **只输出完整版，不压缩字符数**：默认且始终保留完整段落和细节；不输出 ≤ 1500 中文字符的短版。即使用户使用 `--compact`、短版、紧凑版、压缩版或平台限制类措辞，也继续保留时间轴、镜头规则、五拍节奏、材质细节、物理来源和关键限制。

- 仅生成提示词，不调用任何视频生成 API
- 用户拿到提示词后自行粘贴到 Seedance 2.0 平台（火山引擎 / BytePlus / 即梦等）
- 如用户后续需要其他视频模型适配，提示其本 skill 仅针对 Seedance 2.0 优化

**用户追问常见场景**：

- 「换个星座」 → 重新执行步骤 1-5，输出全新版本，不要做小改
- 「画面感觉是固定不动的」 → 检查镜头段是否仍写了「始终保持同一机位」「不要推近不要拉远」等否定式约束；改用「连续手持观察感 + 允许小幅微运镜 + 时间轴里给镜头分配反应性动作」
- 「最后画面有硬切」 → 检查时间轴 8.8-10.0 段是否还在描述「最终停在 XX 英雄角度」；改为「保持原有机位与距离，最终完成感来自机械展开后的姿态」
- 「画面贴得太近」 → 检查是否写了镜头距离 45-60cm、主体占画面比例、四周桌面留白；删除「车头占据画面主体」等容易让车头放太大的句子
- 「动作太顺滑像变形金刚」 → 检查全局动作语义段是否完整保留五拍微循环和「高延迟、重阻尼、强摩擦」等关键词；删除「流畅 / 顺滑 / 灵活」等污染词

- 「表面缺乏层次 / 像素模型」 → 检查是否写了"装甲哑光磨砂 / 拉丝主面 + 抛光金属骨架 / 锁环 / 机芯框"双层对比，以及螺栓头嵌微光 LED 状态点
- 「警示色块 / 警戒条带太像贴纸」 → 改写为"工业涂装、机械产品标识、刻蚀图腾、铭牌灯带"，强调与装甲分缝同走向；不允许出现脱离机械结构的纯图形装饰

- 「变形太快了」 → 默认变形段约 7 秒；如果平台支持更长时长，可扩到 12-15 秒版本
