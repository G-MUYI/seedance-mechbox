# Seedance 机械魔盒优化提示词生成器

基于 `skills/_shared/seedance-prompt-research.md` 的最佳实践重构版本。

## 核心改进

1. **提示词长度**：从 900-1600 字符压缩到 **200-400 字符**（约 100-200 词）
2. **权重分配**：参考素材(22%) + 任务描述(18%) + 镜头/时间(17%) 优先
3. **时间轴格式**：采用 `[0s] [3s] [6s]` 显式时间戳
4. **单 beat 简化**：每个时间点只描述 1 个主动作 + 1 个主镜头
5. **正向守则**：删除大部分否定约束，改为正向描述

## 执行步骤

1. **解析输入**：判断星座模式或通用模式，查表确定目标物
2. **反推魔盒**：从目标物反推初始形态（简化版，只保留核心特征）
3. **填入优化模板**：使用下文的精简模板
4. **直接输出**：不输出解释过程

## 关键删减说明

### 删除的内容（从原版 900-1600 字符）

1. ❌ **详细镜头设定**（150 字）→ 压缩为 1 句话
   - 删除："摄影者站在桌前双手手持设备观察物体，画面持续带有轻微呼吸起伏..."
   - 保留："第一人称手持拍摄，轻微俯视 3/4 侧前视角"

2. ❌ **详细场景描述**（80 字）→ 压缩为 1 句话
   - 删除："略带细小划痕、少量指纹和灰尘点的哑光白色桌面..."
   - 保留："哑光白色桌面，柔和顶光，轻微景深"

3. ❌ **详细人物描述**（60 字）→ 融入时间轴
   - 删除："欧美白人男性双手入镜，手部皮肤质感真实..."
   - 保留：时间轴中的"双手托住魔盒"

4. ❌ **过度详细的主体描述**（400 字）→ 压缩为 5 句话（约 80 字）
   - 删除：所有次要细节（螺栓阵列、LED 状态点、散热栅格、卡扣插槽...）
   - 保留：核心识别点（启动键、锁环、机芯窗、轴承、铭牌）

5. ❌ **十二星座详细规则**（100 字）→ 融入主体和时间轴
   - 删除：独立段落
   - 保留：{符号} 在关键位置出现

6. ❌ **全局动作语义详细描述**（200 字）→ 压缩为 1 句话
   - 删除："整条视频机械动作气质：高延迟、重阻尼、强摩擦、阶段性停滞..."
   - 保留："机械动作：高延迟、重阻尼、串行展开"

7. ❌ **冗长的时间轴描述**（约 500 字）→ 改为时间戳格式（约 120 字）
   - 删除：阶段一、阶段二、阶段三...的详细描述
   - 保留：`[0s] [2s] [4s] [6s] [8s] [10s]` 6 个时间点，每个 1 句话

8. ❌ **全局机械与物理规则**（150 字）→ 压缩为 2 句话
   - 删除：详细的质量守恒、材质统一、音频描述
   - 保留："所有零件从魔盒外壳、滑轨、套筒中推出，传力路径清楚"

9. ❌ **真实感强化**（120 字）→ 压缩为 1 句话
   - 删除：详细的尺度、接触、制造痕迹描述
   - 保留："保持真实接触阴影、金属高光、轻微呼吸式手持观察"

10. ❌ **关键限制**（4 条否定约束）→ 删除
    - 研究报告建议：优先用正向守则，否定约束最多 1-2 条
    - 当前版本：已通过正向描述覆盖，不需要额外否定

### 保留的核心内容

✅ **参考素材模式分流**（有图时最高权重 22%）
- `@Image1 作为 {车型} 外观参考`

✅ **任务描述**（权重 18%）

✅ **关键识别点**
- 启动键、锁环、机芯窗、轴承、铭牌、{符号}

## 使用建议

1. **默认使用优化版**：符合 Seedance 2.0 最佳实践
2. **保留原版作为参考**：`generator.md` 包含完整的生成逻辑和规则
3. **用户可选**：如果用户明确要求"详细版"，使用原版；否则使用优化版

## 实现方式

修改 `SKILL.md`，让它优先读取 `generator-optimized.md`：

```markdown
## Workflow

1. Read `references/generator-optimized.md` for the optimized prompt template.
2. If user explicitly requests "detailed version" or "完整版", read `references/generator.md` instead.
3. Parse the requested target, zodiac sign, or vehicle type.
4. Apply the mapping table and fill in the template.
5. Return the final prompt directly.
```
