# Seedance 世界杯国家队机械魔盒提示词生成器（对应 /seedance-world-cup-mechbox 命令）

为 Seedance 2.0 生成“世界杯 / 足球国家队线索 -> 倒推目标物 -> 机械魔盒坠落 -> 严格串行展开为目标物”的中文提示词。本 skill 的核心不是复刻球衣、队徽、FIFA 标志或官方世界杯视觉，而是从国家队气质、足球战术风格、经典位置角色、比赛器物、球场结构、球衣色彩、号码感、草皮线条、球网结构、看台灯架、奖杯金属感和主客场色彩中倒推出一个可以机械展开的具体目标物。若用户明确要求“像真实世界杯球员”“像某个球星”“卡通球星”“Q 版球员”“球星人偶”“明星球员形状”，可进入可识别明星球员拟态模式，把最终目标物做成能看出真实球员来源的卡通机械球星人偶。

默认策略：**国家 / 国家队倒推优先；人物线索默认转成位置角色和动作原型；可识别明星球员拟态模式只在用户明确要求“像某位真实球员 / 能看出是谁 / 卡通球星人偶”时启用**。国家队路径更稳定，视觉符号更宽，目标物更容易机械化，也更少触发球衣商标、官方队徽和时效阵容问题。普通人物路径不把真实姓名作为画面识别目标，而是提取位置、号码感、动作节奏、装备模块和国家队色调；显式拟态模式下的“像真实球员”也必须是卡通化、机械化、非照片级的拟态，不输出队徽、赞助商、厂牌 logo 或伪官方背书。

提示词结构参考 `seedance-mechbox` 的稳定骨架，并吸收 `skills/_shared/seedance-prompt-research.md` 的结论：提示词过长、否定太密、单个 beat 塞太多动作会冲淡前半段意图。本 skill 输出“核心骨架完整版”：保留第一人称手持实拍、单镜头连续性、主体反推、世界杯机械化转译、5 个以内时间 beat、质量守恒、真实接触和关键限制；删除重复解释和长篇 ban list。

## 路径选择规则

1. **只有国家队**：走国家队映射表，目标物要有足球语义和明确机械来源。
2. **国家队 + 人物**：默认国家队是主路径，人物是副调味。若用户明确要“像真实球员 / 能看出是谁 / 卡通球员 / 球星人偶”，则人物拟态成为目标物主形态，国家队成为配色、动作和足球文化来源。可以使用卡通化脸型、真实发型特征、胡须轮廓、真实国家队球衣特征和真实球衣号码特征增强识别，但不要照片级真人脸、队徽、赞助商或厂牌 logo；没有这些明确措辞时，只提取位置、动作、号码感和装备模块。
3. **只有人物**：默认把人物转为“国家队弱线索 + 位置角色 + 招牌动作 + 号码感 + 装备模块”，不把真实姓名写入画面识别目标。例：知名 10 号 -> 组织核心 / 弧线传球 / 大头短身机械人偶；速度型边锋 -> 边线冲刺 / 折叠翼片 / 低趴冲刺人偶；门将 -> 扑救盾 / 折叠手套框架 / 大手套守门人偶。只有用户明确要求“像某某 / 能看出是谁”时，才保留真实姓名作为可识别拟态参考。
4. **只有角色**：直接走角色映射表。
5. **用户指定目标物**：尊重目标物，但补足球机械来源、国家队配色、球场结构和串行展开逻辑。

## 可识别明星球员拟态模式

仅当用户要求“像真实世界杯球员”“能看出来是哪位球员”“像某个球星”“卡通球星”“Q 版球员”“明星球员人偶”时启用。目标是让观众能识别出真实世界杯球员来源，但画面必须是明确卡通化、机械化、收藏人偶化的风格，不是照片级真人复刻、深度伪造或伪官方宣传。若用户只给姓名或只说“按球星倒推”，默认仍转为角色原型，不启用可识别真实人物拟态。

1. **整体比例**：使用卡通机械收藏人偶比例，开放式头部略大，身体短而结实，四肢为可见关节和液压套筒。比例可夸张，但必须是可动机械实体，不是软萌布偶或真实人体。
2. **脸部与发型处理**：允许卡通化、非照片级的可识别面部拟态：简化脸型比例、眉眼弧线、胡须轮廓、真实发型特征、发型剪影或肤色大色块。头部必须开放无遮挡，真实发型、额头轮廓、眉眼、鼻梁、嘴部或胡须等识别点要清楚可见；机械结构只能作为耳侧、后脑、颈部、下颌边缘或发际线外侧的细小支架、接缝、螺钉和发光刻线，不能使用任何覆盖头发、脸部、眼睛、鼻口或胡须的结构。必须保持玩具化、机械化、夸张比例和非写实材质，避免真实皮肤毛孔、照片级五官、真人视频感或 deepfake 风格。
3. **球星识别来源**：从真实球员姓名输入、国家队色调、真实球衣识别特征、真实球衣号码特征、位置角色、惯用脚、标志性外观轮廓、招牌动作、庆祝姿态、跑动节奏、球鞋 / 护腿板 / 手套 / 队长臂章等机械部件建立相似感。
4. **服装处理**：必须保留真实国家队球衣特征：主色和辅色、领口形状、袖口色条、肩部线条、胸前号码位置、短裤和球袜色调、条纹或几何暗纹。背后号码只能转译为贴合背部曲面的浅浮雕刻线、肩胛小编号或窄薄号码片，后背不做独立厚块、外凸后壳或挂载式方形结构。把这些特征机械化为球衣式装甲分区、织物感微纹理、号码式金属板、发光刻度和拼接护甲；不要出现真实队徽、赞助商、俱乐部 logo、运动品牌厂牌 logo、真实姓名背印或完整官方球衣复刻。
5. **号码处理**：使用该球员在世界杯国家队语境中最具识别度的真实号码，优先作为胸甲机械号码板、肩部小编号、腿部刻度或球鞋侧面的编号件。只有在用户明确要求背面展示时，才允许出现贴合背部装甲曲面的薄型号码刻线；背面号码必须像衣料上的印号或薄装甲刻线一样贴合人偶身体。号码要醒目、位置接近真实球衣号码习惯，但字体和边框应机械化，避免完全复刻官方号码字体。
